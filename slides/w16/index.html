아이트래킹 포비티드 렌더링

무대 스포트라이트 : 관객이 보는 배우에게만 강한 조명 · 고정 조명(FFR)은 무대 중앙만 밝음 · 추적 조명(ETFR)은 배우를 따라감 → 같은 전기로 더 작은 원을 더 정확히

동향 · 2

포비티드 — 얼마나 아끼나 (손계산)

화면을 세 구역으로 나눈 예 · 해상도를 가로·세로 각각 절반 → 픽셀 수 1/4

\[ 0.2 \times 1 + 0.3 \times \tfrac{1}{4} + 0.5 \times \tfrac{1}{16} \approx 0.31 \]

중심 20% 원래대로 · 중간 30% 1/4 · 바깥 50% 1/16 → 계산할 픽셀 약 31% (약 3분의 1)

  • 연구 : 시선 추적 포비티드로 셰이딩 픽셀 수 10~15배 감소 · 5~6배 가속 (Guenter et al. 2012, 데스크톱 실험)
  • 근거 : 중심와(시야 중심 약 2°)만 선명 · 주변시 해상도 급감 (6주)
  • 한계 : 시선이 순간적으로 튈 때 선명 영역이 늦게 따라오면 거친 화면이 보임 → 시선 추적 지연이 작아야 함

현재 수업 장비 Quest 3 = 아이트래킹 없음 → FFR 만 · 아이트래킹은 일부 상위 헤드셋(Quest Pro · Apple Vision Pro · PS VR2 등)에 탑재 · 세부 사양은 기기·세대마다 다름

Guenter et al. (2012) ACM TOG · Patney et al. (2016) — 12주 성능 파트와 연결
동향 · 3

햅틱 — 손끝으로 확인하기

  • 지금 쓸 수 있는 것 : 컨트롤러 진동 — 진폭(0~1) · 지속 시간(초) 두 값으로 요청 · XRI 3.x 의 햅틱 컴포넌트로 잡기·버튼 이벤트에 연결
  • 연구·고급 제품 : 진동 파형 디자인 도구 · 햅틱 장갑 · 초음파 공중 촉각 · 힘 되먹임 장치
  • 지각 근거 : 시각과 촉각이 같은 순간에 일어나면 가상 손을 내 손처럼 느끼는 경향 (고무손 착각 · Botvinick & Cohen 1998) → 늦은 진동은 오히려 어색함

휴대폰 키보드 진동 : 화면 유리를 눌렀을 뿐인데 «톡» 진동이 오면 버튼을 누른 확신 · 진동이 늦게 오면 두 번 누르게 됨

보완 작업 아이디어 : 잡기 성공 순간 짧은 진동 (예 : 진폭 0.3 · 0.05초) → 14주 «잡기 실패» 관찰이 있던 팀에 효과

고무손 착각의 측정 지표 타당도는 논쟁 중 — vr-심리학-근거 7절

공간 비디오 — 촬영한 입체 영상

  • 무엇 : 사람 눈 간격 정도 떨어진 두 렌즈로 동시에 촬영 → 왼눈·오른눈에 각각 재생 → 양안 시차로 입체감 (4주 IPD · 5주 양안 시차)
  • 어디서 : 일부 스마트폰·헤드셋이 직접 촬영 · 여러 헤드셋에서 재생 · 파일 형식·지원 범위는 기기·버전마다 다름
  • 한계 : 촬영 위치에서 본 두 장면만 존재 → 머리를 옆으로 움직여도 운동 시차 없음 (5주) · 정해진 시점에서 보는 «입체 창문»
  • 비교 : 360° 영상 = 둘러보기 가능 · 보통 입체감 약함 / 6DoF 캡처(예 : 3D 가우시안 스플래팅) = 걸어 들어가 볼 수 있는 장면 복원 — 활발히 연구·제품화 중

뷰마스터 장난감 : 원판에 왼눈용·오른눈용 사진 두 장 → 들여다보면 입체 · 고개를 돌려도 장면 안을 둘러볼 수는 없음 → 공간 비디오 = 움직이는 뷰마스터

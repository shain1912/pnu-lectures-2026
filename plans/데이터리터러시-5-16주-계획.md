## 5주 · z-점수·표준화·비교·이상치

**도입 질문** — 국어 80점, 수학 80점 · 더 잘한 과목은?

### 개념 (Part I)

- 원점수의 한계 : 과목마다 난이도·분포 상이 → 같은 80점의 의미 상이
- 기준 두 개 : 평균(위치) · 표준편차(흩어짐) — 4주차 연결
- z-점수 : `z = (원점수 − 평균) / 표준편차` · 단위 소거 → 서로 다른 척도 비교 가능
- 예시
  - 국어 : 평균 85 · 표준편차 5 → z = −1.0
  - 수학 : 평균 60 · 표준편차 10 → z = +2.0
- z 해석 : 0 = 평균 · +1 = 평균보다 표준편차 한 칸 위 · 음수 = 평균 미만
- 정규분포 경험 규칙 : ±1σ 68% · ±2σ 95% · ±3σ 99.7%
  - **대칭 종형일 때만 성립**
- 이상치 기준 3종 비교

| 기준 | 계산 | 강점 | 약점 |
|---|---|---|---|
| z ±3 | 평균·표준편차 사용 | 계산 간단 | 이상치가 평균·표준편차를 끌어당김 |
| IQR 1.5배 | 사분위수 사용 | 치우친 분포에 강함 | 이봉 분포에서 과소 탐지 |
| 도메인 규칙 | 현실 범위 지정 | 의미 기반 | 규칙 근거 문서화 필요 |

- 표준화 기준 선택 : 전체 기준 vs 집단 기준 → 결론 변동
- 이상치 처리 3안 : 유지 · 분리 보고 · 제외 → 어느 경우든 **행 수와 이유 기록**

### 판단 (Part II)

- 제거 전 질문 3개 : 입력 오류인가 · 실제 극단값인가 · 분석 질문에 포함 대상인가
- 극단값 제거 시 평균·표준편차 변화폭을 함께 보고
- 보고 문장 형식 : `기준 · 제외 행 수 · 제외 전후 평균` 3종 병기

## 7주 · 상관계수와 산점도

**도입 질문** — 상관계수가 모두 0.8 인 네 그림 · 직선 관계인 것은?

### 개념 (Part I)

- 산점도 읽기 4요소 : 방향 · 형태 · 강도 · 이상치
- 공분산 → 피어슨 상관계수 r · 범위 −1~+1 · 단위 소거
- 해석 구간 (분야별 기준 상이)
  - |r| 0.0~0.2 미미 · 0.2~0.4 약함
  - 0.4~0.7 중간 · 0.7 이상 강함
- 결정계수 r² : r = 0.7 → r² = 0.49 → 변동의 약 49% 설명
- 스피어만 순위상관 : 순서형·비선형 단조 관계에 사용
- r 의 한계

| 한계 | 예 |
|---|---|
| 비선형 관계 | U자 관계에서 r ≈ 0 |
| 이상치 의존 | 점 하나로 r 0.1 ↔ 0.8 이동 |
| 범위 제한 | 상위권만 뽑으면 r 축소 |
| 집단 혼합 | 두 집단 합산 시 방향 반전 |
| 생태학적 오류 | 지역 평균의 상관을 개인에게 적용 |

- 4주 앤스컴 4중주 재등장 : 요약 통계 동일 · 모양 상이

### 판단 (Part II)

- 보고 형식 : r · n · 산점도 · 이상치 처리 내역 4종 병기
- 결론 문장 강도 점검 : «관련» 허용 · «증가시킴» 금지 (9주 예고)

| 원인 | 요청 범위에 시각화·인과 표현 제한 미포함 |
| 진단 | 모든 쌍 산점도 확인 · 이상치 제외 후 r 재계산 · 결론 문장의 동사 점검 |

### 데모 — `d07.js`

## 11주 · A/B 결과·통계적 유의성·p값

**도입 질문** — p = 0.03 · 효과 확실 여부는?

### 개념 (Part I)

- 표본 변동 : 같은 조건 반복 시에도 차이 발생 → 차이의 크기만으로 판단 불가
- p값 정의 : 귀무가설이 참일 때 관측값 이상의 차이가 나올 확률
- p값의 오해 3종 : «효과가 없을 확률» · «효과 크기» · «재현 확률» — 모두 오답
- 0.05 기준의 임의성 · 분야별 관행 차이
- 효과 크기와 신뢰구간 : 유의 여부보다 **크기와 범위** 중심 보고
- 다중 비교 : 지표 20개 검정 시 우연 유의 1개 기대 · 보정 개념
- 조기 종료(peeking) : 중간 확인 반복 시 거짓 양성 급증
- 3주 «표준편차 감소» 연결 : 대치로 흩어짐이 줄면 유의 판정이 쉬워짐

### 판단 (Part II)

- 결과 보고 4종 : 효과 크기 · 신뢰구간 · n · 검정 횟수
- 판단 문장 : «차이 관측 · 실질 의미 판단 별도»
- 실무 기준 : 사전 등록 지표 1개 · 나머지는 탐색 결과로 표기

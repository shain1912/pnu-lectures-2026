## 2. 주차별 설계

### 5주 · 조명과 재질 : 라이팅 모델, PBR 머티리얼과 라이트매핑

- **도입 질문** : 같은 모델 · 같은 재질 · 조명만 교체 → 한쪽만 «플라스틱 장난감» 으로 보이는 이유는?
- **이론 I (60분)**
  - 광원 4종 : Directional · Point · Spot · Area → 감쇠와 비용 비교
  - Lambert 확산반사 : `N·L` = 2주차 내적의 재등장 · 코사인 감소의 기하학적 의미
  - Blinn-Phong 정반사 : 하프벡터 · 광택도(shininess)
  - 렌더링 방정식 개관 → BRDF 개념 · PBR (metallic / roughness / albedo)
  - **감마 vs 선형 색공간** : 중간 회색 0.5 의 함정 · sRGB 변환 위치
  - 전역조명 · 라이트맵 베이킹 · 라이트 프로브
- **이론 II — 지각 짝 (30분, LaValle Ch.6)**
  - 단안 깊이 단서 : 폐색 · 상대 크기 · 결 기울기 · **음영과 그림자** · 대기 원근
  - 접촉 그림자 유무에 따른 «떠 있는 물체» 착각
  - 양안 시차만으로 공간감이 생기지 않는 이유 → VR 조명의 역할 = 렌더링 품질 이상
  - 조명 베이킹이 VR 필수인 이유 : 실시간 그림자 = 두 눈 × 픽셀 비용
- **AI 함정 #4** : 실시간 그림자 남발 + 색공간 혼동
  - 증상 : 에디터는 정상 · 헤드셋에서 프레임 급락 · 베이킹 후 색이 바래 보임
  - 원인 : Realtime 그림자 다중 광원 · Color Space 를 Gamma 로 둔 채 PBR 사용
  - 진단 : Frame Debugger 로 그림자 패스 확인 · Project Settings 의 Color Space 확인
- **데모** `slides/_shared/demos/w05.js` — 깊이 단서 실험실
  - 조작 : 그림자 on/off · 접촉 그림자 · 상대 크기 · 결 기울기 · 대기 원근 · 양안 시차 토글
  - 확인 : 단서 하나씩 제거 시 «어느 쪽이 더 가까운가» 판단 실패 지점
- **도해** (matplotlib) : `w05-cosine-falloff.svg` · `w05-brdf-lobe.svg` · `w05-gamma-linear.svg` · `w05-depth-cues.svg` · `w05-bake-vs-realtime.svg`
- **실습 50분** : 명세에 «Linear 색공간 · 그림자 1개 · 나머지 베이크» 제약 명시 → 두 버전 비교 · 프레임타임 측정
- **지각 실험실 누적** : 내 씬에 깊이 단서 5종을 스위치로 붙이기

### 6주 · 셰이더 기초 : Shader Graph 커스텀 셰이더, 텍스처 매핑과 UV

- **도입 질문** : 모니터에서 깨끗한 격자 무늬가 헤드셋에서 지글거리는 이유는?
- **이론 I (60분)**
  - 정점 셰이더 / 프래그먼트 셰이더 역할 분담 · 보간(barycentric)
  - UV 매핑 · seam · 타일링
  - 텍스처 필터링 : bilinear · trilinear · anisotropic
  - **밉맵과 앨리어싱** : 나이퀴스트 한계 · 미니피케이션
  - 노멀맵 원리 : 탄젠트 공간 · 법선 교란 (2주차 외적의 재등장)
  - Shader Graph : 노드 = 수식 · 디자인 전공 친화 구간
- **이론 II — 지각 짝 (30분, LaValle Ch.5)**
  - 중심와 vs 주변시 · 시각 예민도 곡선 · 사이클/도
  - **각해상도 PPD** : Quest 3 약 25 PPD vs 인간 한계 약 60 PPD
  - 스크린도어 · 렌즈 왜곡 후 주변부 해상도 손실
  - 포비티드 렌더링(고정·아이트래킹 기반) 원리
  - VR 에서 앨리어싱이 유독 거슬리는 이유 : 머리의 미세 진동 → 프레임마다 샘플 위치 이동
- **AI 함정 #5** : 밉맵 비활성화 · 알파 블렌딩 남용
  - 증상 : 먼 텍스처의 반짝임 · 투명 오브젝트의 앞뒤 뒤바뀜
  - 원인 : Generate Mip Maps 해제 · 반투명 정렬은 깊이 버퍼로 해결 불가
  - 진단 : 카메라 이동 시 노이즈 관찰 · Alpha Clip 대안 비교
- **데모** `w06.js` — 해상도·앨리어싱 실험실
  - 조작 : PPD 슬라이더 · 밉맵 on/off · 머리 진동 진폭 · 중심/주변 시야 마스크
  - 확인 : 같은 텍스처가 PPD 25 에서 무너지는 지점
- **도해** : `w06-mipmap-chain.svg` · `w06-acuity-curve.svg` · `w06-ppd-compare.svg` · `w06-tangent-normal.svg` · `w06-alpha-sort.svg`
- **실습 50분** : Shader Graph 로 «거리에 따라 디테일이 사라지는» 재질 제작 → 명세에 밉맵·필터링 조건 포함
- **지각 실험실 누적** : 실험실 바닥을 고주파 패턴으로 교체 → 앨리어싱 재현·완화

### 7주 · 애니메이션 시스템과 물리 엔진 기초

- **도입 질문** : 화면 속 배경만 흘러가는데 **내 몸이 기울어지는 느낌**이 드는 이유는?
- **이론 I (60분)**
  - 키프레임 보간 : 선형 · 에르미트 · 베지어 · 이징 곡선
  - 스켈레탈 애니메이션 · 스키닝 · 블렌드 트리 · Timeline
  - 강체 운동 · 수치 적분 : 오일러 vs 세미implicit vs 베를레 · 적분 오차 누적
  - 충돌 판정 : broad phase(AABB·BVH) → narrow phase · 연속 충돌(CCD)
  - 고정 타임스텝 재확인 (3주차 연결) · 보간 렌더링
- **이론 II — 지각 짝 (30분, LaValle Ch.8)**
  - **광학 흐름**과 벡션 : 시야를 채운 움직임 → 자기운동 착각
  - 벡션 강도 요인 : 시야각 · 주변시 자극 · 대비 · 지속 시간
  - 전정-시각 충돌 = 멀미의 근원 (2주차 전정계 재등장)
  - **가속이 등속보다 나쁜 이유** : 전정계는 가속에 반응, 등속에는 무반응
  - 12주 컴포트 설계의 이론적 토대
- **AI 함정 #6** : Transform 직접 이동으로 Rigidbody 무력화

- **데모** `w07.js` — 벡션·적분 실험실
  - 조작 : 광학 흐름 속도 · 시야각 마스크(60° / 100° / 전체) · 가속 vs 등속 · 적분기 선택
  - 확인 : 시야각 확대 시 착각 강도 증가 · 오일러 적분의 궤도 이탈
- **도해** : `w07-easing-curves.svg` · `w07-integrators.svg` · `w07-broad-narrow.svg` · `w07-optic-flow.svg` · `w07-vection-factors.svg`

## 해야 할 것

### 1. 결과물 (40)

같은 메뉴 UI 를 두 벌로 제작 · 지각 실험실 프로젝트 안에서

| 버전 | 조건 |
|---|---|
| **A · Overlay** | Screen Space – Overlay · 에디터에서 정상 동작 |
| **B · World Space** | Scale 0.001 · 카메라 앞 **0.5~2 m** · 정면 **±30°** 안 · 본문 글자 **24 DMM 이상** |

공통 기능

- 점수 표시 · «계속» · «종료» 버튼
- Escape → 일시정지 (메뉴 표시) · «계속» 또는 Escape → 복귀
- 상태는 `enum` 하나로 관리 (Menu · Playing · Paused) · 일시정지 중 Player 액션 맵 비활성
- 5주차 깊이 단서 스위치 중 **2개 이상**을 B 패널의 버튼으로 조작

### 2. 프롬프트 명세 (30)

- 명세 4칸 (목표 · 제약 · 검증 조건 · 비목표) 원문
- 제약에 **숫자** 포함 : Render Mode · Scale · 거리 · 각도 · 글자 크기
- 재프롬프트 기록 최소 1회 : AI 가 무엇을 틀렸고 → 어떤 개념 용어로 → 어떻게 다시 요구했는지

### 3. 검증 리포트 (30)

- `CanvasAudit` 로그 2종 : A 만 활성 / B 만 활성 (B 에서 `Overlay 0개`)
- **각크기 측정표** — 거리 3곳 (0.3 m · 1.5 m · 3 m)

| 거리 | 손계산 θ | 로그 θ | 글자 DMM | 어긋남 Δ (D, 초점면 1.5 m 가정) | 판정 |
|---|---|---|---|---|---|
| 0.3 m | | | | | |
| 1.5 m | | | | | |
| 3.0 m | | | | | |

- 손계산 과정 1개 이상 (식 + 숫자)
- 구독 해제 검증 : 패널 토글 5회 후 클릭 → 콜백 1회 로그
- **11주 예측** 3줄 : A 는 헤드셋에서 ___ · B 1.5 m 는 ___ · 0.3 m 는 ___

주차실험실에 있어야 할 것시연 방법

① 시연

좋은 시연의 순서

  1. 한 문장 소개 — «이 씬은 ○○ 를 확인하는 실험대»
  2. 스위치 하나 끄기 — 무엇이 무너지는지 먼저 보여 줌
  3. 다시 켜기 — 원래대로 돌아오는 것 확인
  4. 숫자로 확인 — 콘솔 로그나 화면 표시로 측정값 제시
  5. 2~4 를 2~3회 반복

과학관 실험 시연자 : «촛불에 유리컵을 덮으면 꺼집니다» 를 말로만 하지 않음 → 덮어서 꺼지는 것을 보여 주고, 컵을 떼고 다시 켜 보임 → 원인을 하나만 바꿔 결과가 바뀌는 모습이 곧 설명

비유의 한계 : 과학관은 결과가 정해진 쇼 · 여기서는 실패한 스위치도 그대로 보여 주는 것이 감점 아님

- 시연 중 오류가 나면 그 자리에서 «무엇이 원인일지» 말하게 함 — 그게 구술의 예고편 - 예쁜 연출(음악, 컷씬)은 점수와 무관하다고 다시 강조
② 구술 방어

구술 방어 = «설명할 수 있는가» 확인

내비게이션 운전 vs 길 설명 : 내비를 따라 목적지에 도착한 사람 · 길을 아는 사람 → 둘 다 도착은 함 · 차이는 «왜 이 길로 왔나», «이 다리가 막히면 어디로 돌아가나» 를 물었을 때 드러남

AI 코드 = 내비 · 씬이 작동 = 도착 · 구술 방어 = 내비를 끄고 길을 설명해 보는 시간

  • 이유 : 작동하는 코드만으로는 이해했는지 · 우연히 돌아가는지 구분 불가
  • 그래서 : 코드를 화면에 띄워 둔 채 «이 줄이 없으면 무엇이 무너지나» 를 질문
  • 모든 질문의 출처 = 2~7주 AI 함정 → 수업에서 이미 재현·진단해 본 내용
- 겁주지 않기 : 처음 보는 문제가 아니라 매주 실습한 함정에서만 출제 - 코드는 학생 본인 것을 띄움 — 교수 코드가 아님
② 구술 방어

무엇을 보는가 — 답의 세 칸

1 증상

무엇이 어떻게 잘못 보이나 · 언제(어떤 조건에서) 나타나나

예 : 피치를 90° 근처로 올리면 좌우 회전과 기울이기가 같은 움직임

2 원인 개념

그 증상을 만드는 그래픽스 개념을 정확한 용어로

예 : 오일러각의 회전축 두 개가 겹침 → 자유도 3 → 2 (짐벌락)

3 확인 · 수정

무엇을 측정해서 판정하나 · AI 에게 무엇을 요구하나

예 : Quaternion 누적 요구 · 피치 89~91° 구간에서 회전 튐 0 확인

한 칸만 맞혀도 부분 점수 · 세 칸이 이어져야 만점 → «증상 → 왜 → 그래서 무엇을 확인» 의 이유 사슬

② 구술 방어

막혔을 때 쓰는 방법

  • 모른다고 말하기 + 확인 방법 제시 → «원인은 확실하지 않지만, ○○ 를 끄고 비교해 보면 판별 가능» — 세 번째 칸 점수 인정
  • 증상부터 말하기 → 원인이 떠오르지 않아도 첫 칸은 확보
  • 코드를 짚으며 생각하기 → 화면의 줄을 가리키며 «이 줄이 매 프레임 실행되니까…» 처럼 소리 내어 추론

의사의 «검사해 봅시다» : 진료실에서 바로 병명을 모르는 의사도 «혈액 검사로 확인하겠습니다» 라고 말함 → 모른다는 사실과 확인 방법을 함께 말하는 것이 전문가의 답

감점 큰 답 : 틀린 원인을 확신하며 말하기 · «AI 가 그렇게 짜 줬다» 로 끝내기

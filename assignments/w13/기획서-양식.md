## ① 경험 한 줄 정의 · 대상 · 체험 시간

**쓰는 공식** : «[대상]이 [자세·장소]에서 [핵심 행동]을 하며 [느낌]을 [몇 분] 동안 경험한다»

| 항목 | 내용 |
|---|---|
| 한 줄 정의 | |
| 대상 사용자 | |
| 자세 | 선 자세 / 앉은 자세 / 둘 다 |
| 체험 시간 | 분 (권장 3~5분) |
| VR 필요성 | 아래 세 질문 중 «예» 인 것과 이유 |
| 민감 소재 · 중단 방법 | 공포·높이·폭력·특정 집단의 몸 체험 등 여부 · 체험자가 중단하는 방법 |

**VR 필요성 세 질문** — 셋 다 «아니오» 면 반려 대상

1. 몸의 크기·거리 감각이 경험의 핵심인가
2. 머리·손의 실제 움직임이 주된 입력인가
3. 둘러싸임(뒤·옆·위)이 의미를 바꾸는가

**예시**

- 흐린 정의 : «힐링되는 숲 VR 체험»
- 선명한 정의 : «시험 기간 대학생이 앉은 채로 숲속 연못가에서 돌을 집어 물수제비를 뜨며 4분간 호흡을 고른다»
- 체험 시간 근거 : 노출 10분 이상 연구의 SSQ 평균 33.42 · 10분 미만 23.47 (Saredakis et al. 2020 메타분석) · 15주 시연 10분에 체험자 2~3명

| 회전 = 스냅 턴 22.5° · 이동 = 텔레포트 | 가속·회전 시야 흐름이 벡션 유발 · 전정계는 가속에 반응 | 7·11·12주 · Farmani & Teather 2018 | SSQ 전후 · 중단자 수 |
| 90Hz 고정 · 실시간 그림자 0~1개 | 프레임 지연·변동이 멀미 요인 · 두 눈 렌더 비용 | 3·5·12주 | 헤드셋 실측 fps |

**용어 풀이**

- 단안 깊이 단서 : 한쪽 눈으로도 거리를 아는 단서 (그림자 · 크기 · 가려짐 · 바닥 무늬)
- 벡션 : 몸은 가만히 있는데 시야 흐름 때문에 «내가 움직인다» 고 느끼는 착각
- 조절-수렴 충돌 : 두 눈은 물체 거리에 모이는데 초점은 화면 거리에 고정되어 생기는 피로

## ③ 컴포트 등급 선언

| 항목 | 내용 |
|---|---|
| 선언 등급 | Comfortable / Moderate / Intense |
| 근거 (숫자 · 기법) | |
| 확인 방법 | |
| Intense 인 경우 | 사유 + 대체 모드(텔레포트 등) |

**등급 기준 (이 수업의 정의 · Meta 스토어 3단계 표시 체계 차용)**

| 등급 | 조건 |
|---|---|
| Comfortable | 시점 이동 없음 또는 텔레포트 · 회전은 몸으로 또는 스냅 턴 · 고정 기준(바닥·지평선) 항상 보임 |
| Moderate | 연속 이동 일부 (등속 · 느리게) · 베그넷 등 완화 기법 · 높이·좁은 공간 등 약한 자극 |
| Intense | 가속 이동 · 부드러운 회전 · 낙하·롤러코스터 · 강제 시점 · 고정 기준 없음 |

**예시**

- 근거 없는 선언 : «Comfortable — 편안하게 만들 예정»
- 근거 있는 선언 : «Moderate — 연속 이동 1구간 (등속 0.8 m/s · 가속 없이 즉시 전환) · 회전은 스냅 22.5° · 이동 중 베그넷 · 확인 : 체험 전·직후 SSQ, 중단자 수»
- 참고 수치 : 전방 등속 이동의 멀미 임계 평균 약 1.18 m/s (SD 0.84 · 개인차 큼 → 평균보다 낮게 · Terenzi & Zaal 2020)

> 15주 동료 평가에서 «선언 등급 = 체감 등급» 일치 여부를 물음 · 과소 선언은 감점 사유

| 컨텍스트 윈도우 (Context window) | AI 가 한 번에 볼 수 있는 글의 최대 분량 — «시험장 책상 넓이» |
| 토큰 (Token) | AI 가 글을 읽고 쓰는 단위 조각 · 사용량·요금의 단위 |
| 시스템 프롬프트 (System prompt) | 대화 맨 앞에 깔려 모든 답에 적용되는 기본 지시 |
| 규칙 파일 | 프로젝트 폴더에 두면 코딩 에이전트가 매 요청마다 자동으로 읽는 지시 파일 · 이름은 도구마다 다름 (예 : OpenCode 는 `AGENTS.md`) |
| 할루시네이션 (Hallucination) | AI 가 없는 함수·설정을 그럴듯하게 지어내는 현상 |
| 명세 4칸 | 목표 · 제약 · 검증 조건 · 비목표 (3주차 양식) |
| 실기 검증 | 헤드셋에 빌드를 넣고 실제로 써서 확인하는 검증 |

### 4-1. 검증 조건 바꿔 쓰기 예문

| 판정 불가 (인상) | 판정 가능 (측정) |
|---|---|
| 부드럽게 회전 | 초당 45° · 피치 85~95° 구간에서 프레임 간 각도 변화 5° 이하 |
| 어느 PC 에서나 같은 속도 | 30 · 120fps 제한에서 10초 이동 거리 차 1% 이하 |

## 5. 재발 방지 규칙 — 함정을 규칙 파일로

> 비유 — **오답 노트** : 다시 풀기만 하면 또 틀림 · 규칙 한 줄로 적어 두어야 다음에 막힘

- 작성 원칙 : 한 줄에 **금지 + 대안 + 이유(함정 번호)**
- 이 절의 내용을 그대로 팀 규칙 파일(예 : `AGENTS.md`)에 복사
- 너무 길면 매 요청 컨텍스트를 차지 → **한 화면 안**

### 5-1. 공통 규칙 (카탈로그 부록 A — 필요 없는 줄은 삭제 가능, 이유 기록)

```markdown
- 회전 누적에 eulerAngles 금지 → Quaternion 곱 (짐벌락 · #1)
- 이동·회전은 초당 값 × Time.deltaTime (프레임 독립 · #2)
- GetComponent/Find 는 Awake 에서 한 번 (#2)
- Camera near ≥ 0.1 · far/near ≤ 5,000 (#3)
- 실시간 그림자 광원 최대 1개 · 나머지 Baked · Color Space = Linear (#4)
- 3D 텍스처 밉맵 켬 · 구멍만 필요하면 Alpha Clip (#5)
- Rigidbody 는 FixedUpdate 에서 linearVelocity/AddForce (#6)
- VR Canvas 는 World Space · Tracked Device Graphic Raycaster (#7)
- Main Camera Transform 쓰기 금지 → XR Origin 이동 (#8)
- 이동 가속 곡선 금지 → 즉시 등속 · 스냅 턴 (#9)
- 성능 판정은 헤드셋 실측만 (#10)
```

## 7. 반복 루프 규칙

```
① 명세 → ② AI 생성 → ③ 실행 → ④ 측정 → ⑤ 합격선 판정
                                         ├ 합격 → 로그 기록 · 다음 기능
                                         └ 불합격 → ⑥ 피드백 작성 → ① 또는 ②
```

### 7-1. 피드백 작성법

| 상황 | 방식 | 넣을 것 |
|---|---|---|
| 콘솔 에러 · 예외 · 컴파일 오류 **있음** | 로그 원문 붙이기 | 첫 에러 메시지 전체 + 스택 트레이스 + 해당 줄 · 수천 줄 전체 금지 |
| 에러 **없이** 결과만 틀림 (깜빡임 · 떨림 · 멀미) | 증상 요약 | [조건] [현상] [측정] [기대] [해 본 것] [추측·미검증] |

### 7-2. 멈춤 규칙

- 같은 증상 3회 연속 불합격 → 멈춤 · 원인 가설을 사람이 먼저 세우기 (어느 주차 함정인가?)
- AI 가 고쳤다 되돌리기를 반복 → 새 세션 + 요약 + 실패한 접근을 제약에 «쓰지 말 것» 으로
- 수정 범위가 점점 넓어짐 → 비목표에 «○○ 파일 수정 금지» · 버전 관리로 이전 상태 복구
- 매 바퀴마다 **새 정보 하나**(측정값 · 로그 · 제약)가 추가되지 않으면 그 요청은 보내지 않음

## 8. 코드 리뷰 체크리스트 — AI 코드 병합 전

| # | 확인 항목 | 관련 |
|---|---|---|

| 2 | Update 의 이동·회전에 deltaTime 이 곱해졌는가 · 단위가 «초당» 인가 | #2 |

| 7 | Canvas 가 World Space 인가 · Main Camera Transform 에 쓰지 않는가 | #7 · #8 |
| 8 | 이동에 가속 곡선(SmoothDamp · Lerp)이 없는가 | #9 |

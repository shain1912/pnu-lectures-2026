### 작성법

- 크리틱의 대상 = **씬과 프롬프트** · 사람이 아님
- 세 칸 모두 채우기 — 칭찬도 같은 세 칸으로
- 평가어(«멋있음» · «어색함» · «별로») 단독 사용 금지

> 비유 — **음식 평가** : «맛없어요» 는 요리사가 고칠 방법이 없음 · «국물이 짜요 (관찰) — 간장을 두 번 넣으신 것 같아요 (근거) — 물을 반 컵 더하면 (제안)» 은 다음 요리를 바꿈

| 칸 | 쓰는 것 | 예 |
|---|---|---|
| 관찰 | 본 것 그대로 · 조건 + 현상 | 공이 떨어질 때 바닥을 1프레임 뚫었다 튀어나옴 |
| 근거 | 수업 개념과 연결 (몇 주차 무엇) | 빠른 물체 + 이산 충돌 판정 (7주 · 함정 #6) |
| 제안 | 확인 방법 또는 명세에 넣을 문장 | Collision Detection 을 Continuous 로 바꿔 20회 낙하 비교 |

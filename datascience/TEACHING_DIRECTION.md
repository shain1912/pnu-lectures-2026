## 3. 교육 방향에 대한 해석

다음은 공식 목표·주차 구성·과제·설치 자료에 근거한 해석이다. 교수자의 추가 의도를 확정한 발언으로 취급하지 않는다.

### AI를 활용해 비전공자도 직접 분석하는 수업

교수목표는 프로그래밍 경험이 없는 학생도 데이터를 직접 분석하는 경험을 쌓도록 명시한다. AI 활용은 학기 후반의 별도 특강이 아니라 1주차 환경 설정부터 3주차 정제 실습, 팀 프로젝트까지 이어지는 기본 수행 방식이다.

설치 자료는 Node.js, Git, GitHub CLI, OpenCode, VSCode, Claude Code, Codex CLI, Antigravity와 참고 가이드로 구성되어 있다. 초보자에게 실제 설치 화면, 터미널 여는 법, 설치 성공 확인, 오류 대응까지 제공한다. 이를 보면 학생이 자기 PC에서 AI 에이전트를 실행하고 파일을 다루는 데까지 안내하려는 방향으로 읽힌다. 다만 자료에 포함된 모든 도구를 학생이 반드시 설치해야 한다는 조건은 확인되지 않았다.

### 분석 결과를 비판적으로 읽고 판단하는 능력이 중심

공식 목표는 데이터 기반 사고와 의사결정이다. 평균·분포·z-점수·상관관계·인과관계·A/B 테스트를 배우는 이유는 수치와 그래프가 무엇을 의미하고 어디까지 주장할 수 있는지 판단하기 위해서라고 해석된다.

따라서 실습에서 결과물을 만드는 것과 함께, 사용한 개념과 해석 근거를 설명하는 활동이 어울린다. 단, 프롬프트 로그 제출 의무나 별도 구술시험은 공식 계획에서 확인되지 않았으므로 이미 정해진 정책처럼 적용하지 않는다.

### 직접 비교하고 만들어 보면서 함정을 이해

6주차 과제는 같은 데이터로 정직한 차트와 왜곡된 차트를 만드는 것이다. 5주차는 z-점수로 데이터 비교, 7주차는 두 변수 간 상관관계 분석, 10주차는 일상 속 A/B 테스트 설계, 11주차는 결과 해석 연습이다.

이 과제들은 개념 설명 → 실제 적용 → 결과 비교·해석으로 연결된다. 특히 차트 과제는 학생이 표현 방법을 바꾸며 왜곡을 직접 확인하게 하는 교육 장치다.

### 학생의 관심과 현실의 의사결정으로 연결

2주차부터 관심 주제의 공공데이터를 찾게 한다. 12주차에는 비즈니스·사회 문제 사례, 데이터 윤리와 개인정보를 다루고, 13~15주차에는 팀별 분석 계획·수행·스토리텔링·발표로 이어진다.

학생이 질문을 정하고, 실제 데이터를 분석하고, 결과를 다른 사람에게 전달하는 경험이 학기의 완성 지점이라고 해석된다. 결과의 표현과 윤리적 판단도 분석 역량의 일부다.

## 5. 기존 가안에서 바로잡아야 할 점

- 과목명과 목표를 ‘데이터리터러시의이해’에 맞춘다.
- 회귀·분류·모델 성능 평가를 후반부 필수 단원으로 배치했던 가안은 사용하지 않는다. 공식 후반부인 인과·A/B 테스트·의사결정을 기준으로 삼는다.
- 8주차 개인 탐색 프로젝트 가안을 중간고사라는 공식 평가 조건에 맞춰 다시 설계한다. 구체적인 시험 형식은 아직 확인되지 않았다.
- 2주차는 데이터 종류·구조·수집과 관심 주제 공공데이터 찾기에 맞춘다. 이전 전시 방문 합성 사례는 보조 예시 후보로만 남긴다.
- 학생용 실습을 노트북 방식으로 고정하지 않는다. 이미 제공된 로컬 AI 에이전트 환경과 연결되는 실행 방식을 먼저 검토한다.
- 주교재는 PDF 제공이라는 기준이 있다. HTML 슬라이드를 쓰더라도 PDF 배포를 충족하도록 추후 설계한다.
- 다른 과목의 과제·평가·운영 규칙을 이 과목의 확정 조건으로 가져오지 않는다.

현재 단계는 교육 방향 파악이다. 새로운 강의자료 구현과 평가 정책 확정은 진행하지 않았다.

종류 · 1

데이터의 세 가지 형태

정형 (Structured)

행과 열이 정해진 표
엑셀, CSV, 데이터베이스

바로 계산 가능

반정형 (Semi-structured)

구조는 있으나 표 형태는 아님
JSON, XML, 로그 파일

표로 펼친 뒤 계산 가능

비정형 (Unstructured)

텍스트, 이미지, 음성, 영상
리뷰 글, 사진, 통화 녹음

숫자로 변환 후 계산 가능

현실의 데이터 : 대부분 비정형
분석 기법 : 대부분 정형 데이터 전제
→ "표로 만드는 일"이 분석의 절반

설계 · 1 ★

수집 설계의 올바른 순서

설계 · 2

조작적 정의 — 말을 숫자로 바꾸기

"통학시간이 길다" 그대로는 분석 불가 → 측정 방법부터 결정

말조작적 정의 (예시)이 정의가 빠뜨리는 것
통학시간집 문을 나서서 강의실 도착까지의 분환승 대기, 도보 구간
인기 있는 강의수강신청 마감까지 걸린 초재수강, 필수과목 여부
위험한 교차로연간 인명사고 건수통행량 차이

완벽한 정의는 없음
분석 전에 정의를 문서로 남기고, 놓치는 부분도 함께 명시

설계 · 3

데이터 출처

설문

원하는 변수를 직접 설계 가능
질문 문구에 따라 응답 변화
유도질문·척도 설계의 영향 큼

공공데이터

data.go.kr · KOSIS
큰 규모, 높은 신뢰도
내 질문에 딱 맞는 데이터는 드묾

웹 수집

공개되지 않은 데이터 확보 가능
이용약관·저작권·개인정보
수집 기술보다 적법성 판단이 먼저

이번 학기 실습 데이터 : 공공데이터
– 정제가 필요한 현실 그대로의 상태
– 행정·정책에 실제로 쓰이는 데이터
– 출처 확인이 가능한 실재하는 데이터

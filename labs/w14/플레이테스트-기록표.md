# 플레이테스트 기록표 — 14주차

- 체험자 1명당 1부 · 운영 팀(우리 팀)이 작성
- 세션 최대 10분 · 진행자는 스포터 겸임 · 안전·중단 요청 외 개입 금지
- SSQ 문항지와 문항별 묶음(N·O·D) 표 : «팀프로젝트 가이드북»

**용어**

- 진행자 : 동의 · SSQ · 과업 전달 · 안전 담당 (힌트 금지)
- 관찰자 : 캐스팅 화면과 체험자 몸을 보며 시각·행동·발화 기록
- 생각 말하기 : 체험자가 보고·생각하는 것을 소리 내어 실시간으로 말하는 방법
- SSQ : 멀미 증상 16개를 0~3 점(없음·약간·중간·심함)으로 묻는 설문

## 6. SSQ 직후 (헤드셋 벗고 바로)

| 묶음 | 문항 점수 합 | 가중치 | 점수 |
|---|---|---|---|
| 오심 n | | × 9.54 | |
| 안구운동 o | | × 7.58 | |
| 방향감각 상실 d | | × 13.92 | |
| **총점 T** | n+o+d = | × 3.74 | |
| **변화 (직후 − 사전)** | | | |

**계산 예** : 사전 n=1 · o=2 · d=0 → T = 3.74 × 3 ≈ 11.2 · 직후 n=3 · o=4 · d=2 → T = 3.74 × 9 ≈ 33.7 → 변화 +22.4

| 멀미 프로토콜 단계 | 해당 시 표시 |
|---|---|
| 1 미열감·침 분비 → 이동 중단 | □ |
| 2 어지러움·두통 → 헤드셋 해제 · 착석 | □ |
| 3 메스꺼움 → 종료 · 당일 재체험 금지 | □ |
| 체험 시간 (시작~종료) | 분 초 |

**해석 주의** : 절단점(위험 기준 점수) 합의 없음 · 표본 2~4명 → 통계 결론 불가 · 전후 · 버전 간 비교와 중단자 수 · 발화를 함께 읽기

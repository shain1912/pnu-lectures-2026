# 데이터사이언스 수업 설계안

> **기존 가안 보류:** 공식 과목은 「데이터리터러시의이해」다. 아래 시범 주차·평가·실습 형식은 공식 계획 확인 전에 만든 제안이며 확정 사항이 아니다. [교육 방향 파악](TEACHING_DIRECTION.md)을 기준으로 추후 수정한다.

상태: 검토용 가안 · 상위 계획: [PLAN.md](PLAN.md)

수강 대상과 공식 강의계획서는 미확정이다. 이 문서는 비전공 입문 수준에서도 사용할 수 있는 활동·평가·시범 주차의 설계 초안이다. 시간표, 배점, 기술 환경을 확정한 문서가 아니다.

## 1. 학기 전체를 관통하는 경험

학생은 하나의 관심 분야를 선택하고, 전반부에는 데이터를 설명하는 분석을, 후반부에는 비교 또는 예측을 포함하는 분석을 완성한다. 후반부에서 데이터를 바꾸어도 되지만 질문·데이터·방법의 적합성을 다시 설명해야 한다.

매주 남기는 기록은 다음 여섯 항목으로 통일한다.

1. 질문: 누구의 어떤 판단을 돕고 싶은가?
2. 데이터: 한 행은 무엇이고, 누구 또는 무엇이 빠져 있는가?
3. 방법: 어떤 처리·비교를 했고 왜 선택했는가?
4. 증거: 어떤 표·그래프·측정값이 답을 뒷받침하는가?
5. 검증: 결과가 잘못되었을 가능성을 어떻게 확인했는가?
6. 한계: 이 데이터로 주장할 수 없는 것은 무엇인가?

AI 사용 내역은 활용한 경우에 추가한다. 프롬프트의 길이나 도구 종류보다 결과를 확인하고 수정한 근거를 평가한다.

## 2. 학습 목표와 평가의 연결

| 목표 | 처음 다루는 주 | 반복 확인 | 평가 증거 |
|---|---|---|---|
| 분석 가능한 질문 정의 | 1 | 8, 13, 15 | 질문·대상·관찰 단위가 명확한 기획서 |
| 데이터 구조와 품질 이해 | 2~4 | 모든 분석 | 데이터 사전, 행 수·결측·중복 점검 |
| 분포와 차이를 시각적으로 설명 | 5~6 | 8, 9, 15 | 그래프 선택 이유와 해석 |
| 불확실성과 인과 해석의 한계 설명 | 7, 9 | 8, 15 | 일반화 범위와 대안 설명 |
| 예측을 타당하게 평가 | 10~12 | 14~15 | 기준모델·분할·평가 지표·누수 점검 |
| 분석 재현과 전달 | 3부터 반복 | 14~16 | 처음부터 실행 가능한 분석물과 발표 |

중간 프로젝트는 탐색적 분석까지 평가한다. 아직 배우지 않은 예측 모델을 요구하지 않는다. 기말 프로젝트는 확정된 강의 범위에 따라 비교·추론 또는 예측 중 적용 가능한 경로를 사용한다.

## 3. 평가 설계 가안

학기 성적 비중은 공식 조건 확인 후 정한다. 아래 기준은 과제와 프로젝트의 질을 판단하는 공통 기준이며 성적 배점이 아니다.

| 평가 축 | 충분한 수행 | 보완이 필요한 수행 |
|---|---|---|
| 질문과 데이터의 적합성 | 질문·대상·단위가 일치하고 필요한 변수를 설명 | 흥미로운 주제만 있고 데이터가 질문에 답하지 못함 |
| 처리의 타당성 | 정제·집계·분할의 이유와 전후 변화를 기록 | 결과만 있고 처리 근거가 없거나 단위를 혼동 |
| 검증 | 손계산·행 수 점검·대조 분석 등 실제 확인 증거 제시 | 실행 성공이나 AI의 설명만으로 정확하다고 판단 |
| 해석 | 결과에 맞는 강도의 결론과 한계를 제시 | 상관을 인과로 단정하거나 관찰 범위를 넘어 일반화 |
| 재현과 전달 | 입력·실행 순서·그림 설명을 갖추고 재실행 가능 | 파일 누락, 숨은 실행 상태, 출처·축·단위 누락 |

잘못된 첫 결과를 발견하고 근거 있게 고치는 과정도 평가 증거로 인정한다. 구술 확인은 “왜 이 분모를 썼는가?”, “이 행을 제외하면 무엇이 달라지는가?”처럼 학생의 판단을 확인하는 질문으로 구성한다.

## 4. 시범 주차: 2주차 상세 설계

### 수업의 출발 질문

> 전시 A의 평균 체류 시간이 더 길다. 그렇다면 A가 더 인기 있는 전시인가?

이 질문에서 관찰 단위, 변수의 의미, 집계 기준, 주장 범위를 배운다. 전시 사례는 과목 분야가 미정인 상태에서 만든 교체 가능한 교육용 예시다.

### 학습 목표

- 표의 한 행과 각 열의 의미·자료형·단위를 설명한다.
- 방문 기록 수와 고유 방문자 수를 구분한다.
- 작은 표의 집계 결과를 손계산과 코드로 교차 확인한다.
- 체류 시간만으로 인기나 만족도를 단정할 수 없는 이유를 설명한다.

### 교육용 합성 데이터 초안

실제 사람의 행동을 기록한 데이터가 아니다. 식별자·집계 단위를 배우기 위한 여섯 행의 예시다.

| visit_id | visitor_id | exhibit | dwell_minutes |
|---|---|---|---:|
| V01 | P01 | A | 10 |
| V02 | P01 | A | 20 |
| V03 | P02 | A | 30 |
| V04 | P03 | B | 15 |
| V05 | P04 | B | 15 |
| V06 | P05 | B | 15 |

- 한 행은 전시 방문 기록 1건이다. 사람 1명과 동일하지 않다.
- `visit_id`는 방문 기록 식별자, `visitor_id`는 방문자 식별자다. 식별자에 산술 평균을 적용하지 않는다.
- 전시별 방문 기록 수는 A·B 각각 3건이다. 전시별 고유 방문자는 A 2명, B 3명이다.
- 방문 기록 기준 평균 체류 시간은 A 20분, B 15분이다.
- A의 방문자별 평균 체류 시간은 P01 15분, P02 30분이며, 이 두 값의 평균은 22.5분이다. 방문 기록에 같은 가중치를 주는 것과 방문자에 같은 가중치를 주는 것은 다른 질문이다.
- 어느 집계도 전시 만족도나 인과 효과를 직접 측정하지 않는다.

### 수업 진행 비율

주당 시간이 미정이므로 전체 활동 시간을 100으로 놓는다. 실제 시간표에는 휴식과 환경 문제 대응 시간을 별도로 반영한다.

| 비율 | 활동 | 학생이 남길 증거 |
|---:|---|---|
| 10% | 출발 질문과 직관적 답 비교 | 첫 판단 한 문장 |
| 20% | 행·열·식별자·수치·범주 설명 | 데이터 사전 |
| 15% | 여섯 행 손계산과 짝 토론 | 방문 건수·방문자 수·평균 표 |
| 25% | 준비된 노트북으로 읽기·집계 실행 | 실행 결과와 손계산 대조 |
| 20% | 잘못된 분석 설명 검토와 수정 | 오류·근거·수정문 |
| 10% | 출발 질문 재답변과 제출 안내 | 최종 결론과 한계 |

첫 실습은 환경 설치와 자유 코딩을 동시에 요구하지 않는다. 제공된 노트북에서 실행·관찰·작은 수정으로 시작하고, 문법은 필요한 지점에서 설명한다. Python 경험이 있는 반이면 직접 집계 코드를 작성하는 확장 활동을 추가한다.

### 의도적으로 제시할 오류

교수자가 “행이 3개씩이니 방문자 수도 같다”라는 잘못된 분석 설명을 제시한다. 학생은 반복되는 `visitor_id`를 근거로 오류를 반박한다. AI가 우연히 오류를 생성해야 성립하는 활동으로 만들지 않는다.

추가 질문은 “A가 더 인기 있다”라는 결론을 어떻게 고칠지다. 예시 답은 “이 표에서 방문 기록 기준 평균 체류 시간은 A가 길지만, 고유 방문자는 B가 많다. 인기의 정의와 추가 데이터가 필요하다”이다.

### 과제 초안

제출물은 데이터 사전, 집계표, 검증 기록, 결론과 한계 각 한 문장이다. 코드 또는 노트북을 함께 제출한다. AI를 활용했다면 제안 내용 중 채택·수정한 부분과 확인 방법을 짧게 기록한다.

필수 확인:

- 방문 기록 수와 고유 방문자 수를 구분했는가?
- 평균의 분모와 관찰 단위를 명시했는가?
- 손계산과 실행 결과가 일치하는가?
- 체류 시간과 인기를 동일시하지 않았는가?

### 시범 제작 산출물과 완료 기준

| 산출물 | 설계 범위 | 완료 기준 |
|---|---|---|
| 슬라이드 | 질문 → 표 읽기 → 집계 비교 → 오류 수정 | 설명과 표가 일치하고 글자가 수업 화면에서 읽힘 |
| 학생 노트북 | 데이터 읽기·확인·집계·해석 빈칸 | 새 실행 상태에서 처음부터 완료 가능 |
| 데이터 및 사전 | 위 합성 데이터와 변수 설명 | 행·식별자·단위 정의가 일치 |
| 과제 명세 | 제출물·필수 활동·판단 기준 | 수업에서 다룬 개념만으로 수행 가능 |
| 교수용 해설 | 기대값·오답·보충 질문 | 학생용 배포 파일에 정답이 섞이지 않음 |

## 5. 데이터 준비 원칙

초기에는 손으로 검증할 수 있는 합성 데이터로 시작한다. 실제 데이터는 관찰 단위와 정제 개념을 익힌 뒤 도입한다.

| 구간 | 데이터 성격 | 선정·제작 조건 |
|---|---|---|
| 2~3주 | 작은 합성 표 | 손계산 가능, 식별자·결합 관계 명확 |
| 4~7주 | 결측·분포·집단 차이가 있는 교육용 데이터 | 의도한 오류와 생성·가공 이력 기록 |
| 중간 프로젝트 | 출처가 확인된 실제 공개 데이터 후보 | 다운로드 가능, 이용 조건 명확, 질문에 필요한 변수 존재 |
| 10~12주 | 예측 시점과 목표 변수가 명확한 데이터 | 기준모델 가능, 분할 단위·누수 위험 설명 가능 |
| 기말 프로젝트 | 학생 선택 또는 제공 후보군 | 출처·규모·단위·범위 사전 점검 |

구체적인 공개 데이터 후보는 과목 분야를 정한 후 조사한다. 합성 데이터에서 나타난 패턴을 실제 사회·이용자의 특성으로 해석하지 않는다.

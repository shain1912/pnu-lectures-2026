## 실습 3 · 상태 기계 + 액션 맵 전환 (10분)

### ① 개념
- bool 4개 = 2⁴ = 16 조합 → enum 상태 하나로 «한 번에 하나만»
- 일시정지 중엔 **Player 맵을 끄고 UI 맵을 켬** → 메뉴 고르는 동안 캐릭터가 걷지 않음
- 상태 전환은 **한 함수**(`SetState`)에서만

### ② 명세 (추가 요청)

```
[목표] Escape(Player/Pause) → Paused, UI/Cancel 또는 «계속» 버튼 → Playing.
[제약] 상태는 enum GameState { Menu, Playing, Paused } 하나로 관리, bool 플래그 금지.
       상태 전환 함수 한 곳에서 액션 맵 전환·패널 표시·Time.timeScale 을 함께 처리.
[검증 조건] 전환마다 "[GameState] → 상태 · 켜진 맵" 로그 1줄.
            Paused 상태에서 이동 키(WASD) 입력 시 플레이어 위치 변화 0.
[비목표] 저장·불러오기.
```

### ③ 검증

| 시도 | 기대 로그 | 실제 | 통과 |
|---|---|---|---|
| Escape | `→ Paused · 켜진 맵 = UI` | | ☐ |
| Paused 중 WASD | 위치 변화 0 | | ☐ |
| «계속» 클릭 | `→ Playing · 켜진 맵 = Player` | | ☐ |
| Escape → Escape | 두 번째 Escape 로 복귀 (UI/Cancel) | | ☐ |

## 실습 4 · 각크기 측정 — 거리 3곳 (12분)

### ① 개념
- 각크기 θ = 2·atan(s / 2d) · 거리 2배 → 약 절반
- DMM = 글자 높이(mm) ÷ 거리(m) · 본문 권고 **24 DMM**
- 조절-수렴 어긋남 Δ = |1/d − 1/1.5| D (초점 고정면 1.5 m 가정 · 기기마다 다름) · 권고 약 ±0.5 D

### ② 명세
`WorldSpaceCanvasPlacer` 의 distance 를 바꿔 가며 `Place World Space` → `CanvasAudit` 실행
(0.3 m 는 슬라이더 범위 밖 → Canvas Position 을 직접 입력)

### ③ 검증 — 표 채우기 (손계산 먼저, 로그 나중)

| 거리 d | 손계산 θ (폭 0.6 m) | 로그 θ | 글자 DMM (36 pt = 36 mm) | 어긋남 Δ (D) | 판정 |
|---|---|---|---|---|---|
| 0.3 m | | | | | |
| 1.5 m | 22.6° | | 24 | 0 | |
| 3.0 m | | | | | |

내적 — 숫자로 직접 계산

계산법 : 같은 자리끼리 곱해서 모두 더하기

\[ \mathbf{a}\cdot\mathbf{b} = a_x b_x + a_y b_y + a_z b_z \]

\[ 1{\times}0.6 + 0{\times}0.8 + 0{\times}0 = 0.6 \]

둘 다 길이 1 → \( \cos\theta = 0.6 \) → 사이 각 약 53° · 양수 → 앞쪽

행렬 — 좌표를 넣으면 새 좌표가 나오는 기계

계산법 : 행렬의 가로줄과 좌표를 같은 자리끼리 곱해서 더하기

\[ \begin{bmatrix} 2 & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} 3 \\ 4 \end{bmatrix} = \begin{bmatrix} 2{\cdot}3 + 0{\cdot}4 \\ 0{\cdot}3 + 1{\cdot}4 \end{bmatrix} = \begin{bmatrix} 6 \\ 4 \end{bmatrix} \]

결과 : 가로만 2배 늘어남 — 이 행렬 = «가로 2배 스케일» 기계

행렬 = 변환 기계 — 입구에 좌표 (3, 4) 를 넣으면 출구로 (6, 4) 가 나옴

기계 안 숫자만 바꾸면 회전 기계, 스케일 기계로 교체

선형변환Linear transform
직선은 직선으로, 원점은 원점에 남기는 변환 — 스케일·회전
기저 벡터Basis vector
좌표의 기준 화살표 · 2D 에서 \( \mathbf{i}=(1,0) \), \( \mathbf{j}=(0,1) \)

회전 · 8

쿼터니언 — 숫자 예와 곱하는 순서

예 : Y축 \( \mathbf{n}=(0,1,0) \) 둘레 90° → \( \sin 45^\circ = \cos 45^\circ \approx 0.707 \)

\[ q = (0,\; 0.707,\; 0,\; 0.707) \qquad \text{(180° 라면 } (0,\,1,\,0,\,0)\text{)} \]

쿼터니언 곱도 순서를 바꾸면 결과가 다름 : \( q_1 q_2 \neq q_2 q_1 \)
Unity 의 a * b = b 를 먼저, 그 다음 a 적용 (행렬과 같은 오른쪽 우선)

Quaternion q = Quaternion.AngleAxis(90f, Vector3.up); // (0, 0.707, 0, 0.707)

transform.rotation = transform.rotation * q;  // 자기 축(로컬) 기준으로 추가 회전
transform.rotation = q * transform.rotation;  // 월드 축 기준으로 추가 회전
- Debug.Log(Quaternion.AngleAxis(90, Vector3.up)) 를 실행해 숫자 확인 - 쿼터니언은 짐벌락을 없애줄 뿐, 순서 문제까지 없애주지는 않음 — 흔한 오해 - 도입 질문의 B(Rotate 두 번)는 첫 번째 줄 방식, A 와 같게 하려면 두 번째 줄 방식

## 1. 주차별 설계

### 5주 · z-점수·표준화·비교·이상치

- **도입 질문** : 국어 80점, 수학 80점 · 더 잘한 과목은?
- **개념 (60분)**
  - 원점수의 한계 : 과목마다 난이도·분포 상이 → 같은 80점도 의미 상이
  - 비교 기준 두 개 : 평균(위치) · 표준편차(흩어짐) — 4주 연결
  - z-점수 : `z = (원점수 − 평균) / 표준편차` → 단위 소거, 다른 척도끼리 비교
  - 예 : 국어 평균 85·표준편차 5 → z = −1.0
  - 예 : 수학 평균 60·표준편차 10 → z = +2.0
  - 해석 : 0 = 평균 · +1 = 평균보다 표준편차 한 칸 위 · 음수 = 평균 미만
  - 경험 규칙 : ±1σ 68% · ±2σ 95% · ±3σ 99.7% — **대칭 종형 분포에서만 성립**
  - 기준 범위 : 전체 기준 표준화와 집단 기준 표준화의 결론 차이

| 이상치 기준 | 계산 | 강점 | 약점 |
|---|---|---|---|
| z ±3 | 평균·표준편차 | 계산 간단 | 이상치에 평균·표준편차가 끌려감 |
| IQR 1.5배 | 사분위수 | 치우친 분포에 강함 | 이봉 분포에서 과소 탐지 |
| 도메인 규칙 | 현실 범위 지정 | 의미 기반 | 근거 문서화 필요 |

- **판단 (30분)**
  - 제거 전 질문 3개 : 입력 오류 여부 · 실제 극단값 여부 · 분석 대상 포함 여부
  - 처리 3안 : 유지 · 분리 보고 · 제외 → 어느 쪽이든 **행 수와 이유 기록**
  - 보고 형식 : 기준 · 제외 행 수 · 제외 전후 평균
- **AI 함정 #4** : 정규분포 가정 이상치 제거
  - 증상 : «이상치 제거해줘» → ±2σ·±3σ 자동 컷 · 제거 행 수 미보고
  - 원인 : 치우친·이봉 분포에서 표준편차 자체가 극단값에 끌려감
  - 진단 : 제거 전후 n 비교 · 히스토그램 확인 · IQR 결과와 대조
- **데모** `dataliteracy/slides/_shared/demos/d05.js` — 표준화 비교기
  - 조작 : 원점수 · 과목 평균 · 표준편차 · 분포 치우침
  - 확인 : 같은 80점의 z 변화 · 치우친 분포에서 ±3σ 에 걸린 값의 실제 정상 여부
- **도해** : `d05-zscore-formula.svg` · `d05-two-subjects.svg` · `d05-normal-68-95.svg` · `d05-outlier-rules.svg` · `d05-skew-breaks-z.svg`

### 7주 · 상관계수와 산점도

- **도입 질문** : 상관계수가 모두 0.8 인 산점도 네 장 · 직선 관계는 어느 것?
- **개념 (60분)**
  - 산점도 읽기 4요소 : 방향 · 형태 · 강도 · 이상치
  - 공분산 → 피어슨 상관계수 r : 범위 −1~+1 · 단위 소거
  - 강도 구간 (분야별 차이 있음)
    - |r| 0.2 미만 미미 · 0.2~0.4 약함
    - 0.4~0.7 중간 · 0.7 이상 강함
  - 결정계수 : r = 0.7 → r² = 0.49 → 변동의 약 49% 설명
  - 스피어만 순위상관 : 순서형 · 비선형 단조 관계
  - 앤스컴 4중주 재등장 : 요약 통계 동일 · 모양 상이 (4주 연결)

| r 의 한계 | 예 |
|---|---|
| 비선형 관계 | U자 관계에서 r ≈ 0 |
| 이상치 의존 | 점 하나로 r 0.1 ↔ 0.8 |
| 범위 제한 | 상위권만 뽑으면 r 축소 |
| 집단 혼합 | 두 집단 합산 시 방향 반전 |
| 생태학적 오류 | 지역 평균의 상관을 개인에 적용 |

- **판단 (30분)**
  - 보고 형식 : r · n · 산점도 · 이상치 처리 내역
  - 결론 동사 점검 : «관련» 허용 · «증가시킴» 금지 (9주 예고)
- **AI 함정 #6** : 산점도 없는 상관표
  - 증상 : 상관 행렬 숫자만 출력 · 높은 r 에 «영향» 표현
  - 원인 : 요청에 시각화·표현 제한 미포함
  - 진단 : 모든 쌍 산점도 확인 · 이상치 제외 후 r 재계산 · 결론 동사 점검
- **데모** `d07.js` — 상관 조작기
  - 조작 : 점 하나 드래그 · 표본 크기 · 관계 유형(선형 · U자 · 두 군집)
  - 확인 : 점 하나로 r 급변 · U자 관계에서 r ≈ 0

# 컴퓨터그래픽스 학기 용어집

**컴퓨터그래픽스 (VF3500076) · 디자인앤테크놀로지전공 · 조성호 · 2026-2**

- 수록 범위 : 1~16주 슬라이드의 용어 풀이(`dl.terms`)와 «용어 미리보기» 전체
- 정렬 : 한글 용어 가나다순 → 영문·숫자 용어 알파벳순
- **첫 등장** : 처음 정의한 주차 · **다시 나온 주** : 다른 주차 슬라이드에서 다시 풀이한 주차
- 같은 용어를 여러 주에서 풀이한 경우 → 가장 완전한 뜻으로 합쳐 한 줄로 정리
- 쓰는 법 : 프롬프트에 넣을 정확한 용어를 고를 때 · AI 답변에 모르는 말이 나왔을 때 먼저 찾기

> 용어를 모르면 프롬프트를 쓸 수 없고, 결과를 검수할 수 없음 — 이 수업의 명제

| 체험 | 시점 | N 원점수 | O 원점수 | D 원점수 | N (×9.54) | O (×7.58) | D (×13.92) | TS ((N+O+D 원점수)×3.74) |
|---|---|---|---|---|---|---|---|---|
| A 유발본 | 직전 | | | | | | | |
| A 유발본 | 직후 | | | | | | | |
| A | **변화량** | | | | | | | |

### 6-3. 공간 UI 버튼 크기 손계산

- 공식 : 한 변 $s = 2d\tan(\theta/2)$ · 최소 각 크기 θ ≈ 3° (Meta 가이드 약 2.5~3°)
- 1.2 m 패널 : $2 \times 1.2 \times \tan 1.5^\circ \approx 0.063$ m → 버튼 6.3 cm 이상
- 내 패널 거리 ______ m → 최소 버튼 크기 ______ cm → 실제 만든 크기 ______ cm
- 확인 : `Canvas` Render Mode = **World Space** · `Tracked Device Graphic Raycaster` 부착 · 레이로 눌리는가 [ ]

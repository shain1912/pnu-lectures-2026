거리에 따른 감쇠 — 역제곱 법칙

\[ E \propto \frac{1}{d^{2}} \]

E : 표면에 닿는 빛의 세기 · d : 광원까지 거리

손계산 — 1 m 에서 밝기 100 일 때
2 m : \(100 \times \tfrac{1}{4} = 25\)
3 m : \(100 \times \tfrac{1}{9} \approx 11\)

스프레이 페인트 : 벽 가까이서 뿌리면 작은 원에 진하게 · 2배 멀리서 뿌리면 원의 지름 2배·넓이 4배 → 같은 양의 페인트가 퍼져 농도 1/4

이유 : 빛이 공 모양으로 퍼짐 → 같은 에너지가 구 표면 넓이 \(4\pi d^{2}\) 에 나뉨 → 거리 2배면 넓이 4배 · 밝기 1/4
Directional 에 감쇠가 없는 이유 : 태양까지 약 1억 5천만 km → 방 안에서 몇 m 움직여도 거리 비율 변화 ≈ 0

Unity 의 Range : 이 거리 밖은 계산 생략 · 경계 근처에서 0 으로 부드럽게 줄이는 설정 — 역제곱 곡선 자체와 별개

- 스프레이 비유 : 멀리서 뿌리면 넓게 퍼지면서 옅어짐 → 빛도 똑같이 넓이 4배에 나뉨 - 손계산 : 100 → 25 → 11, 거리 3배인데 밝기는 1/9 로 급격히 감소

Lambert 확산반사 — 손계산

// 표면 법선 N, 광원 방향 L (둘 다 정규화)
float ndotl = max(0.0, dot(N, L));          // ← 2주차 내적
float3 diffuse = albedo * lightColor * ndotl * intensity;

바닥의 한 점
N = (0, 1, 0) — 바닥이 위를 봄
L = (0.6, 0.8, 0) — 비스듬한 위쪽 광원
길이 확인 : \(\sqrt{0.6^2+0.8^2} = 1\)

\(\mathbf{N}\cdot\mathbf{L} = 0{\times}0.6 + 1{\times}0.8 + 0{\times}0 = 0.8\)
albedo 빨강 (0.8, 0.2, 0.2) · 흰 광원 세기 1
diffuse = (0.64, 0.16, 0.16) — 정면 대비 80% 밝기

법선 — 조명 계산의 기준축

면에 수직으로 꽂은 이쑤시개 : 이쑤시개가 가리키는 쪽 = 면이 바라보는 쪽 · 조명 계산은 «이 이쑤시개와 빛이 이루는 각도» 로 결정

면 법선 = 세 꼭짓점으로 만든 두 변의 외적 (두 화살표에 동시에 수직인 화살표를 구하는 계산 · 2주차)

\[ \mathbf{N} = (B-A)\times(C-A) \]

손계산 : A = (0,0,0) · B = (0,0,1) · C = (1,0,0)
\((0,0,1)\times(1,0,0) = (0,\,1,\,0)\) → 바닥이 위를 향함
B·C 순서를 바꾸면 (0, −1, 0) → 뒤집힌 면

정점 법선 : 한 꼭짓점을 공유하는 면들의 법선 평균 → 면 경계에서 밝기가 매끄럽게 이어짐 → 각진 다면체도 둥근 공처럼 보임

양안 시차가 가까운 곳에서만 강한 이유

엄지 손가락 실험 : 팔을 뻗어 엄지를 세우고 한 눈씩 번갈아 감으면 엄지가 크게 점프 · 창밖 먼 건물은 거의 그대로 → 두 눈 영상의 차이 = 거리 정보 · 멀어질수록 차이가 사라짐

\[ \theta \approx \frac{b}{d} \]

θ : 두 눈이 물체를 보는 각도 차 (라디안) · b : 두 눈 사이 약 6.3 cm · d : 물체까지 거리

거리 d각도 차 θ
0.5 m0.063 ÷ 0.5 ≈ 0.13 → 약 7°
10 m0.063 ÷ 10 ≈ 0.006 → 약 0.4°
100 m약 0.04°

θ 가 1/d 로 줄어듦 → 약 10 m 바깥에서는 거리 근거로 약함 (대략적 경계 · 개인차 큼)

- 학생 모두 엄지 실험 직접 해 보기 → 가까운 엄지는 크게, 먼 벽은 거의 안 움직임 - 숫자로 확인 : 0.5 m 에서 7°, 10 m 에서 0.4° — 20배 거리면 차이 1/20

엄지 실험을 위에서 내려다보면

엄지 손가락 실험의 평면도 · 가까운 엄지는 두 눈의 시선이 크게 벌어져 번갈아 감을 때 크게 점프 · 먼 건물은 두 시선이 거의 겹쳐 그대로

// 프레임타임 평균 (최근 120프레임)
float sum = 0; int cnt = 0;
void Update() {
    sum += Time.unscaledDeltaTime; cnt++;
    if (cnt == 120) { Debug.Log($"{sum / cnt * 1000f:F2} ms"); sum = 0; cnt = 0; }
}

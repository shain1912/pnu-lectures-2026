# 기말 팀 프로젝트 가이드북 (C7)

- 과목 : 컴퓨터그래픽스 VF3500076 · 2026학년도 2학기 · 담당 조성호
- 비중 : **기말 팀 프로젝트 40%** (평가 5축은 8절)
- 기간 : 13주 기획 → 14주 구현·플레이테스트 → 15주 전시·시연·동료 평가 → 16주 피드백
- 함께 쓰는 양식 : [SSQ 설문지](SSQ-설문지.md) · [동료평가 양식](동료평가-양식.md) · [멀미 실습 동의서](../setup/멀미실습-동의서.md) · 12주 [워크북](../labs/w12/워크북.md) 7절 컴포트 체크리스트

> 한 줄 목표 : **«왜 편안한지» 를 지각 이론과 숫자로 설명할 수 있는 3~5분짜리 VR 경험**
> 화려함보다 근거 · 범위보다 완성도 · 에디터가 아니라 **헤드셋에서 잰 숫자**

## 1. 용어 풀이

| 용어 | 뜻 |
|---|---|
| 컴포트 등급 | 체험이 멀미·불편을 줄 수 있는 정도를 팀이 미리 선언하는 3단계 표시 (5절) |
| 성능 예산표 | 드로우콜·삼각형·그림자·텍스처의 **상한**을 미리 정해 두는 표 — 돈 대신 «11.1 ms» 를 나눠 쓰는 계획 |
| 지각적 근거 | «이 인터랙션이 편안하다 · 공간이 이렇게 느껴진다» 를 수업에서 배운 지각 이론으로 정당화한 설명 |
| 플레이테스트 | 만든 사람이 아닌 사람에게 체험시키고, **개입 없이 관찰**해 문제를 찾는 시험 |
| 프롬프트 플레이북 | 9주차 산출물 — 팀이 AI 에게 일을 시킬 때 쓰는 명세 양식·금지 사항·검증 절차 모음 |
| 온디바이스 실측 | PC 에디터가 아니라 Quest 3 에서 직접 실행해 잰 값 (14주 AI 함정 #10) |

## 2. 팀 구성과 역할 4종

- 팀원 **3~4인** · 13주 수업 시작 전까지 확정 (12주 브리핑에서 구성)
- 역할 4종을 **한 사람씩 책임자**로 지정 · 3인 팀은 한 사람이 두 역할 겸임 (검증 역할은 겸임 가능하나 «씬» 과는 겸임 금지 — 자기 씬을 자기가 검증하면 적응·편향)
- 모든 팀원이 코드·프롬프트를 쓰는 것은 자유 · 역할 = «최종 책임과 결정권» 의 소재

| 역할 | 책임 | 주요 산출물 | 14주 플레이테스트 담당 |
|---|---|---|---|
| **씬 (Scene)** | 공간 구성 · 스케일(1 unit = 1 m) · 조명·베이크 · 성능 예산 준수 | 씬 구조도 · 성능 예산표 실측값 | 진행자 |
| **인터랙션 (Interaction)** | 이동 방식 · Grab/Ray · 공간 UI · 입력 바인딩 · 컴포트 옵션 | 인터랙션 명세 · 컴포트 옵션 목록 | 진행자 보조 · 버그 기록 |
| **에셋 (Asset)** | 모델·텍스처·사운드 · 폴리곤·텍스처 상한 관리 · 라이선스 | 에셋 목록 (출처·라이선스·삼각형 수·텍스처 크기) | 관찰자 보조 |
| **검증 (QA)** | 컴포트 체크리스트 · SSQ · OVR Metrics 측정 · 개선 기록표 · 프롬프트 플레이북 관리 | 검증 계획 · 개선 기록표 · SSQ 집계 | **관찰자** (기록 총괄) |

## 4. 기획서 의무 항목

13주 제출 · 분량 자유 (A4 3~5쪽 권장) · 아래 6개 항목이 모두 있어야 접수

### ① 경험 정의

- 경험 한 줄 정의 : «______ 하는 사람이 ______ 을 통해 ______ 을 느끼는 경험»
- 대상 사용자 · 체험 시간 (**권장 3~5분**) · 자세 (앉음 / 서서 제자리 / 방 규모 걷기)
- 왜 VR 이어야 하는가 (화면으로 충분하면 VR 일 이유 없음)

### ② 지각적 근거

- 핵심 인터랙션 2~3개마다 «무엇 → 왜 편안한가 → 근거 이론·수치»
- 예 : «이동은 텔레포트 + 블링크 → 이동 중 광학 흐름이 없음 → 전정-시각 충돌 제거 (LaValle 12.3, 텔레포트 비교 연구)»
- 공간감 : 깊이 단서 보강 계획 (접촉 그림자 · 바닥 무늬 · 친숙한 크기 물체) · VR 거리 과소추정(평균 약 74%, Renner et al. 2013) 대응
- UI 배치 거리·크기 : 패널 약 1~1.5 m · 최소 각 크기 약 2.5~3° · 0.5 m 안쪽 장시간 응시 금지

### ③ 컴포트 등급 선언

- 5절 기준으로 **Comfortable · Moderate · Intense** 중 하나 선언 + 근거 3줄
- 12주 컴포트 체크리스트(유발 요인 6개 × 위험 · 대응 · 측정) 첨부

### ④ 성능 예산표

- 6절 양식 · 목표값 + 측정 방법 · 14주에 실측값 채움

### ⑤ 검증 계획

- 측정 항목 : SSQ (직전·직후) · 체험 시간 · 과업 성공 여부 · 막힌 지점 · OVR Metrics FPS
- 측정 시점 : 직전 · 직후 (가능하면 10분 후)
- **합격 기준**을 숫자로 : 예 «체험자 3명 중 2명 이상 과업 완료 · TS 변화량 평균이 유발본 실습 결과의 절반 이하 · 11.1 ms 초과 프레임 1% 미만»

### ⑥ 프롬프트 플레이북 (9주 산출물) 첨부

- 팀 공용 명세 양식 (목표 · 제약 · 검증 조건 · 비목표)
- 팀 금지어·필수어 : 예 «부드럽게 이동 → 금지 · 등속·즉시 전환 → 필수» (12주 AI 함정 #9)
- AI 생성 코드 검수 절차 (누가 · 무엇을 · 어떤 수치로)

## 5. 컴포트 등급 기준 (수업용)

> 이름은 Meta 스토어가 과거 쓰던 3단계 표기를 빌림 · 판정 기준은 **이 수업용으로 정한 것** (업계 공식 기준 아님)

| 등급 | 이동 | 회전 | 가속·흐름 | 기타 조건 |
|---|---|---|---|---|
| **Comfortable** | 실제 걷기 · 텔레포트만 · 또는 제자리 | 몸으로 돌기 · 스냅 턴만 | 인공 가속 없음 · 시야 전체가 흐르는 장면 없음 | 90 Hz 유지 · 고정 기준(바닥·방) 상시 |
| **Moderate** | 등속 스틱 이동 (약 1.5 m/s 이하) · 즉시 전환 | 스냅 턴 기본 · 부드러운 회전은 옵션 | 짧은 가속 허용 · 이동 중 베그넷 기본 켬 | 컴포트 옵션 메뉴 제공 (텔레포트 대체 가능) |
| **Intense** | 가속 이동 · 비행 · 탈것 · 높은 속도 | 부드러운 연속 회전 · 롤·피치 회전 | 강한 광학 흐름 · 낙하·롤러코스터 | 체험 전 고지 필수 · 동의자만 · 시연 시 별도 안내 |

### 선언 규칙

- 경계에 걸치면 **더 강한 쪽**으로 선언
- 15주 동료 평가에서 관람자가 «선언한 등급과 실제 체감이 일치하는가» 를 표시 → 일치도가 «지각·컴포트 설계 근거» 평가에 반영
- Intense 선언 팀 : 시연 대기열에 고지문 · 완화 옵션(베그넷·텔레포트) 버전도 준비 권장

## 7. 플레이테스트 절차 (14주)

### 7-1. 역할 (고정 · 교대 없음)

| 역할 | 하는 일 | 하지 않는 일 |
|---|---|---|
| **진행자** (체험 팀) | 동의 확인 · 착용 도움 · 과업 1문장 안내 · 안전 (스포터 겸) | 체험 중 힌트·설명 |
| **관찰자** (체험 팀 검증 담당) | 막힌 지점 · 시간 · 발화 · 자세 변화 기록 · OVR Metrics 값 기록 | 개입 |
| **체험자** (다른 팀) | 과업 수행 · 소리 내어 생각하기 (선택) · SSQ 작성 | — |

### 7-2. 순서 (체험자 1명당 약 10분)

1. 동의 확인 (동의서 3·4절 요약 구두 안내 · 대체 역할 안내)
2. SSQ **직전** 작성 (1분)
3. 과업 부여 : «______ 을 해 보세요» 한 문장 · 그 뒤로는 **개입 없이 관찰**
4. 체험 (최대 5분) · 관찰자는 시각과 함께 막힌 지점 기록 · OVR Metrics FPS 기록
5. 헤드셋 해제 → SSQ **직후** (1분)
6. 짧은 인터뷰 (2분) : 가장 헷갈렸던 순간 · 불편했던 순간 · 선언한 컴포트 등급을 알려 주고 «체감과 맞는가»
7. 다음 체험자 전 : 렌즈·위생 커버 정리 · 최소 3명 체험

### 7-3. 개선 기록표 (14주 제출)

| # | 문제 (관찰 사실) | 원인 (이론·수치로) | 조치 | 재측정 결과 |
|---|---|---|---|---|
| 1 | 예 : 3명 중 2명이 회전 후 방향 상실 | 스냅 45° 가 커서 방향 기준 소실 | 22.5° 로 변경 + 바닥 방향 표식 | 재체험 1명 · 방향 상실 없음 |
| 2 | 예 : 복도 구간 FPS 72 강등 | 반투명 안개 파티클 3겹 → GPU 병목 | 파티클 1겹 · 렌더 스케일 0.9 | 90 Hz 유지 · 초과 프레임 0.4% |
| 3 | | | | |

- SSQ 결과는 [SSQ 설문지](SSQ-설문지.md) 4절 «조 단위 집계표» 로 정리 · 해석 규칙 5절 준수

## 8. 평가 연결 (기말 40%)

| 평가 축 | 배점 | 확인 방법 | 근거가 되는 산출물 |
|---|---|---|---|
| 완성도 | 30 | 15주 시연 | 최종 빌드 · 과업이 처음부터 끝까지 동작 |
| **지각·컴포트 설계 근거** | 25 | 기획서 + 질의 | 기획서 ②③⑤ · 컴포트 체크리스트 · SSQ 집계 · 동료평가의 «등급 일치도» |
| 성능 예산 준수 | 15 | 온디바이스 실측 | 성능 예산표 실측 열 · 15주 현장 OVR Metrics 확인 |
| 발표·시연 | 20 | 현장 | 발표 5분 + 시연 10분 + 질의 5분 |
| 동료 평가 | 10 | [동료평가 양식](동료평가-양식.md) | 관람자 평가 평균 |

### 감점 · 불인정

- 카메라 Transform 직접 조작 (11주 함정 #8) · 화면 고정 UI (10주 함정 #7) → 해당 축에서 감점
- 에디터 수치만으로 성능 주장 (14주 함정 #10) → 성능 축 불인정
- «몰입감이 높다» 같은 주장만 있고 측정·근거 없음 → 근거 축 감점
- 프레즌스 설문 점수를 «경험의 질» 증거로 단독 사용 → 불인정 (설문 단독 결론 금지)

### 개인 기여

- 역할별 산출물과 커밋·프롬프트 로그로 확인 · 무임승차가 확인되면 개인 점수 조정 (16주 면담)

## 9. 15주 전시 운영 (안전)

- 부스마다 **스포터 1명** 상주 · 플레이 구역 2 m × 2 m · 가디언 설정
- 세션 사이 렌즈·위생 커버 정리 · 대기열 인원 제한
- Intense 등급 팀 : 대기열 고지문 · 체험 전 구두 안내 · 중단 권리 고지
- 멀미 증상자 발생 시 3단계 대응 ([동의서](../setup/멀미실습-동의서.md) 4절) · 당일 해당 관람자 추가 체험 금지

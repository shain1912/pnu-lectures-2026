## 같은 내용의 다른 형식

| 형식 | 위치 | 용도 |
|---|---|---|
| 배포 주소 | 위 표 | 링크 배포 · 데모 동작 |
| 인쇄용 PDF | `dist/`, `dataliteracy/dist/` | PLATO 첨부 · 데모는 안내 카드로 대체 |
| 오프라인 zip | `dist/*-interactive-slides.zip` | 인터넷 없는 환경 · 압축 해제 후 index.html |
| 원본 | `slides/wNN/index.html` | 수정 대상 |

## 폴더 구성

- `컴퓨터그래픽스/`, `데이터리터러시/` : 주차별 바로가기(`.url`)와 주소 메모(`.txt`)
- `.url` 더블클릭 → 해당 주차 슬라이드 열림

## 공개 범위

- 올린 직후 상태 : **비공개** · 만든 사람만 열람 가능
- 학생 배포 시 각 페이지 우측 상단 **Share** 메뉴에서 공유 범위 지정 필요
- 공유 후 같은 주소를 PLATO 자료 설명·공지에 그대로 사용

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / 스페이스 | 다음·이전 슬라이드 |
| `Esc` | 전체 슬라이드 한눈에 보기 |
| `S` | 발표자 노트 (새 창) |
| 마우스 드래그 | 3D 화면 시점 회전 |

## 갱신

원본(`slides/wNN/index.html`) 수정 → 같은 주소로 다시 올리면 링크 유지.

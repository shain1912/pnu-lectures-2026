### 3-2. 개념 구술 방어 (30점) = 2문항 × 15점 · 4단계 척도

- 문항 : 발표 직전 2문항 추첨 · 기본 Q1~Q6 (주차별 함정 #1~#6) · 꼬리 질문은 질문 은행(주차별 5문항 이상, 안내 문서 §7)에서
- 문항마다 **증상 5 + 원인 개념 5 + 확인·수정 5** 를 채점한 합으로 단계 판정

| 단계 | 점수 | 기술 | 예 (Q6 «Rigidbody 대신 Transform 을 쓰면 무엇이 사라지는가») |
|---|---|---|---|
| **4 · 탁월** | 13~15 | 증상을 조건과 함께 · 원인을 정확한 용어 + 이유 사슬로 · 측정 방법과 **합격 기준 숫자**까지 | «대시 40 m/s 에서 얇은 벽 통과 · 벽 앞 떨림 → 순간이동이라 속도 정보가 사라져 충돌이 아닌 겹침 해소만 일어남 → WallPassTest 20회 중 통과 0회를 기준으로 FixedUpdate + linearVelocity + Continuous Dynamic 확인» + 씬 시연 |
| **3 · 충분** | 9~12 | 증상·원인 정확 · 확인 방법은 있으나 숫자 기준 없음 | «속도가 0 이라 물리 엔진이 충돌로 처리 못 함 · linearVelocity 로 바꾸고 벽에 여러 번 쏴 봄» |
| **2 · 부분** | 5~8 | 현상과 해결책은 알지만 «왜» 가 모호 · 용어 부정확 | «벽을 뚫어서 Rigidbody 로 바꿨음 · 그게 물리적으로 맞음» |
| **1 · 미흡** | 1~4 | «이상해진다» 수준 · 용어 나열 · 틀린 원인 확신 | «Transform 은 느려서요» |
| 0 | 0 | 무응답 | |

- 씬에 해당 기능이 없으면 «내 씬에 넣는다면 어떻게 명세할지» 로 변형 · 첫 답이 약하면 꼬리 질문 1회
- 메모 지참 불가 · 씬 조작은 허용 (보여 주며 설명 = 4단계 근거)

## 4. 기말 팀 프로젝트 (40%) — 5축

형식 : 15주 전시회 · 팀별 부스 · 발표 5분 + 시연 10분(관람자 2~3명 체험) + 질의 5분
현장 채점표 : `rubrics/기말-평가표.md` · 진행 기준 : `rubrics/팀프로젝트-가이드북.md` · 동료 평가 : `rubrics/동료평가-양식.md` (세부 점수 구간은 그 표와 동일)
성능 기준선 (Quest 3 · Unity URP) : 90Hz 고정(11.1 ms) · 드로우콜 150 이하 · 삼각형 프레임당 50만 이하 · 실시간 그림자 광원 0~1개 · 텍스처 2048 이하·밉맵 켬

4단계 대응 : 4 = 우수 · 3 = 양호 · 2 = 미흡 · 1 = 부족

### 4-1. 완성도 (30점)

| 단계 | 점수 | 기술 |
|---|---|---|
| 4 · 우수 | 26~30 | 체험자 전원이 안내 없이 시작~끝 · 크래시·막힘 0 · 핵심 조작이 매끄러움 · 시작 안내와 끝 신호 존재 |
| 3 · 양호 | 20~25 | 대부분 완료 · 1회 정도 막힘 또는 경미한 버그 · 경험 성립 |
| 2 · 미흡 | 12~19 | 과업 완료 절반 이하 · 팀의 구두 설명 필요 · 버그로 흐름 단절 |
| 1 · 부족 | 0~11 | 크래시 · 빌드 실행 불가 · 경험 미성립 |

### 4-2. 지각·컴포트 설계 근거 (25점)

기획서 «지각적 근거» 섹션 + 질의응답 + 동료 평가의 «등급 일치도» 로 판정

| 단계 | 점수 | 기술 |
|---|---|---|
| 4 · 우수 | 22~25 | 이동·회전·UI·조명 결정마다 **«결정 → 원리 → 주차 → 측정»** (예 : 스냅턴 22.5° → 회전 광학 흐름의 불편 임계가 낮음 → 7·12주 → 14주 SSQ 비교) · 질의에 숫자로 답변 · 선언 컴포트 등급과 관람자 체감 일치 · 14주 측정으로 근거 갱신 |
| 3 · 양호 | 16~21 | 근거 대부분 타당 · 측정 일부 누락 · 등급 대체로 일치 |
| 2 · 미흡 | 9~15 | 원리 언급은 있으나 측정 없음 · 등급 과소 선언 · 질의에 «느낌상» 답변 |
| 1 · 부족 | 0~8 | 근거 부재 · 연속 가속 이동·카메라 직접 조작·화면 고정 UI 등 알려진 위험 요인을 인지 못함 |

- 멀미 이론은 «감각 충돌 vs 자세 불안정» 이 논쟁 중 → 한 이론만 정설로 단정한 서술은 3단계 상한
- 프레즌스 설문 점수 단독으로 «경험의 질» 주장 → 근거로 불인정

### 4-3. 성능 예산 준수 (15점)

| 단계 | 점수 | 기술 |

| 3 · 양호 | 9~12 | 평균 80대 또는 간헐적 튐 · 예산 일부 초과를 인지·설명 |

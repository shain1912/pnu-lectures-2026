## 0. 오늘 쓰는 용어 (5분 복습)

| 용어 | 쉬운 뜻 |
|---|---|
| 보간 (Interpolation) | 두 키프레임 사이 값을 계산으로 채우기 |
| 이징 (Easing) | 출발·도착에서 속도를 줄여 부드럽게 만드는 보간 |
| Rigidbody | 물체를 물리 엔진 관리 대상으로 등록하는 컴포넌트 · 질량·속도 보유 |
| Collider (충돌체) | 충돌 판정용 보이지 않는 모양 |
| 고정 타임스텝 (Fixed Timestep) | 물리 계산 간격 · 기본 0.02초 (초당 50번) |
| 터널링 (Tunneling) | 빠른 물체가 한 스텝 사이에 얇은 벽을 건너뛰는 현상 |
| CCD (연속 충돌 판정) | 도착 자리만이 아니라 이동 경로 전체를 검사하는 판정 |
| 보간 렌더링 (Interpolate) | 물리 스텝 사이를 부드럽게 채워 그리는 Rigidbody 설정 |
| 광학 흐름 (Optic flow) | 내가 움직일 때 눈에 맺힌 장면 전체가 흘러가는 패턴 |
| 벡션 (Vection) | 몸은 가만한데 보이는 흐름만으로 움직인다고 느끼는 착각 |

## 3. 과제 B — 명세로 고치기 + 반복 측정 (15분)

### ① 개념

- 동적 물체 = **속도를 정하고 위치는 엔진에 맡김** → `FixedUpdate` 에서 `rb.linearVelocity`
- 터널링 조건 : \(v\,\Delta t\) > 벽 두께 + 물체 크기 → 그때만 Continuous 계열
- 터널링은 시작 위치에 따라 **확률적** → «한 번 해 봤더니 안 뚫림» 은 검증 아님

-

**자기 점검** — 명세에 다음이 들어갔는가 (✔)

- [ ] `transform.position` 대입 금지를 명시
- [ ] 입력은 `Update`, 물리 적용은 `FixedUpdate`
- [ ] 대시 속도와 벽 두께를 숫자로 → Collision Detection 모드를 근거와 함께 지정

## 워밍업 답

- 1-1 : 0.5초 = t 0.25 → 120 × 0.25 = **30°**
- 1-2 : s = 3(0.0625) − 2(0.015625) = 0.15625 → 120 × 0.156 ≈ **18.75°**
- 1-3 : 오일러 0.5초 **0** (옛 속도 0) · 1초 0 + (−5)(0.5) = **−2.5** / 세미암시적 0.5초 속도 −5 → **−2.5** · 1초 속도 −10 → −2.5 + (−10)(0.5) = **−7.5** → 정답 −5 를 사이에 두고 한쪽은 덜, 한쪽은 더 떨어짐
- 1-4 : 25 × 0.02 = **0.5 m** · 0.2 + 0.25 = **0.45 m** → 0.5 > 0.45 → **통과 가능** (시작 위치에 따라)
- 1-5 : 1.4 ÷ 1.5 ≈ **0.93 rad/s** ≈ **53°/s**

## 이 과제가 확인하려는 것

이 수업에서 **코드는 AI 가 씁니다.** 여러분이 하는 일은 두 가지입니다.

1. 무엇을 만들어야 하는지 **정확한 용어와 숫자로 요구하는 것** — 이번 주 : 밉맵 · 필터 · Surface Type · Alpha Clipping
2. AI 가 내놓은 결과가 **왜 틀렸는지 판별하는 것** — 이번 주 : 정지 화면에서는 안 보이는 반짝임, 순서가 뒤바뀌는 잎

그래서 «예쁜 바닥» 이 아니라 **«반짝이지 않는다는 증거»** 를 제출합니다.

## 용어 정리 (리포트에 이 용어로 쓸 것)

| 용어 | 뜻 |
|---|---|
| 밉맵 (Mipmap) | 텍스처를 절반씩 줄여 미리 평균 내 둔 축소판 묶음 |
| LOD | 픽셀마다 고르는 밉맵 레벨 번호 · LOD = log₂(픽셀 하나가 덮는 텍셀 수) |
| Trilinear · Anisotropic | 밉맵 두 레벨을 섞는 필터 · 비스듬한 바닥에서 긴 방향으로 여러 번 읽는 필터 |
| 나이퀴스트 한계 | 무늬 한 주기당 표본(픽셀) 2개 이상 필요 · 미달 → 모아레·반짝임 |
| Alpha Clipping | 알파 기준값 미만 픽셀을 버리는 불투명 처리 · 깊이 버퍼로 순서 자동 해결 |
| PPD | 시야 1° 안의 픽셀 수 · Quest 3 약 25 · 시력 1.0 기준 60 |

## 과제 내용

### A. 거리 페이드 바닥 재질 (필수)

- **Lit Shader Graph** 로 바둑판 바닥 재질 제작
- 카메라와의 거리에 따라 무늬가 평균 회색으로 부드럽게 사라짐 (`Position` · `Camera` · `Distance` · `Smoothstep` · `Lerp`)
- 경계 거리 E₁ · E₂ 는 **본인이 정하고 근거를 적을 것** (예 : PPD 계산으로 «칸 한 주기가 4 픽셀 미만이 되는 거리»)
- 바닥 텍스처 : Generate Mipmap 켬 · Filter Mode = Trilinear · Aniso Level 지정

### B. AI 함정 #5 재현 → 진단 → 수정 (필수)

- 스타터 `W06TrapTextureAlpha.cs` 로 증상 재현 · 녹화
- 원인 줄을 찾아 **개념으로 설명** (나이퀴스트 · 물체 중심 정렬)
- 본인 씬의 잎·철망 등 «구멍만 뚫리면 되는» 재질을 **Opaque + Alpha Clipping** 으로 전환

### C. 지각 실험실 누적 (필수)

- 실험실 바닥을 고주파 패턴으로 교체 + 스위치 3종 : 밉맵 on/off · Filter (Point / Trilinear / +Aniso) · 잎 Blend ↔ Clip

## 자주 묻는 질문

- **Q. 먼 바닥이 회색으로 흐려졌는데 이게 맞나요?**
  → 맞습니다. 그 거리에서 픽셀 하나가 흰 칸·검은 칸을 여러 개 덮으므로 **정답 색은 평균(회색)** 입니다. 흐림이 과하면 Aniso Level 을 올려 보세요.
- **Q. MSAA 를 켰는데 바닥 반짝임이 그대로입니다.**
  → MSAA 는 삼각형 **가장자리** 담당입니다. 텍스처 **안쪽** 반짝임은 밉맵 담당입니다.
- **Q. 유리창도 Alpha Clipping 으로 바꿔야 하나요?**
  → 아니요. 뒤가 반쯤 비쳐 보여야 하는 재질은 Transparent 가 맞습니다. 대신 개수를 줄이고 서로 교차하지 않게 배치하세요.
- **Q. 헤드셋이 없는데 PPD 계산은 어떻게?**
  → Quest 3 약 25 PPD (제조사 발표 · 렌즈 중심 기준) 를 그대로 사용합니다. 헤드셋 실측은 11주차에 합니다.

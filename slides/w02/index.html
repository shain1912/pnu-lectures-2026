벡터의 길이와 정규화

벡터 \( \mathbf{v} = (3, 4, 0) \) 의 길이(크기) — 피타고라스

\[ |\mathbf{v}| = \sqrt{3^2 + 4^2 + 0^2} = \sqrt{25} = 5 \]

각 성분을 길이 5 로 나누면 = 정규화

\[ \hat{\mathbf{v}} = \left(\tfrac{3}{5}, \tfrac{4}{5}, 0\right) = (0.6,\ 0.8,\ 0) \]

정규화 = 나침반 바늘 — «얼마나 멀리»는 지우고 «어느 쪽»만 남김

용어 세 개(크기 · 단위 벡터 · 정규화)는 다음 장 «용어 풀이»

왜 필요한가 : 내적·조명 계산은 길이가 1 이라는 전제 → 정규화를 빠뜨리면 거리에 따라 결과가 커지거나 작아짐

- (3,4,0) 은 3-4-5 직각삼각형 — 손으로 계산 가능한 대표 예 - 비유 : 나침반은 목적지까지의 거리를 알려주지 않고 방향만 알려줌 → 정규화된 벡터 - 다음 슬라이드 시야각 코드에서 .normalized 를 붙이는 이유가 바로 이것

내적 — 숫자로 직접 계산

계산법 : 같은 자리끼리 곱해서 모두 더하기

\[ \mathbf{a}\cdot\mathbf{b} = a_x b_x + a_y b_y + a_z b_z \]

예 : \( \mathbf{a} = (1,0,0) \), \( \mathbf{b} = (0.6,\,0.8,\,0) \)

\[ 1{\times}0.6 + 0{\times}0.8 + 0{\times}0 = 0.6 \]

둘 다 길이 1 → \( \cos\theta = 0.6 \) → 사이 각 약 53° · 양수 → 앞쪽

내적 = 햇빛 아래 막대 그림자 길이

a 를 바닥선으로 두고 햇빛을 바로 위에서 비추면, 길이 1 막대 b 의 그림자 = 0.6

막대가 a 와 나란하면 그림자 1 · 직각으로 서면 0 · 뒤로 누우면 음수

용어 «투영 · cos θ» 는 다음 장 «용어 풀이»

- 칠판에 a=(1,0,0), b=(0.6,0.8,0) 직접 계산 — 곱셈 3번과 덧셈 2번 - 비유 : 정오의 햇빛처럼 a 축에 수직으로 빛이 떨어질 때, 막대 b 가 바닥(a 방향)에 남기는 그림자 길이 - 막대를 세울수록 그림자가 짧아지고, 완전히 세우면(직각) 그림자 0 - 비유의 한계 : 길이가 1 이 아닌 벡터라면 그림자 길이에 a 의 길이가 곱해짐 → 그래서 보통 정규화 후 사용

회전행렬 유도

\( \mathbf{i} = (1,0) \) 을 θ 만큼 회전하면?

\[ \mathbf{i} \;\to\; (\cos\theta,\; \sin\theta) \]

\( \mathbf{j} = (0,1) \) 을 θ 만큼 회전하면?

\[ \mathbf{j} \;\to\; (-\sin\theta,\; \cos\theta) \]

두 도착지를 세로 열로 세운 것 = 회전행렬

\[ R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix} \]

공식 암기 대신 «i, j 가 어디로 가나»만 그리면 언제든 다시 유도 가능

cos θ = 반지름 1 원 위 점의 가로 위치 · sin θ = 세로 위치 (θ 는 반시계 방향 각도)

- 칠판에 반지름 1 원을 그리고 i 를 θ 만큼 돌려 가로·세로 좌표 읽기 - j 는 i 보다 90° 앞서 있으므로 (−sin θ, cos θ) - 수학의 2D 표준 좌표(오른손) 기준 — Unity 3D 의 왼손 좌표계와는 회전 방향 부호가 다를 수 있음

쿼터니언 — 숫자 예와 곱하는 순서

예 : Y축 \( \mathbf{n}=(0,1,0) \) 둘레 90° → \( \sin 45^\circ = \cos 45^\circ \approx 0.707 \)

\[ q = (0,\; 0.707,\; 0,\; 0.707) \qquad \text{(180° 라면 } (0,\,1,\,0,\,0)\text{)} \]

쿼터니언 곱도 순서를 바꾸면 결과가 다름 : \( q_1 q_2 \neq q_2 q_1 \)
Unity 의 a * b = b 를 먼저, 그 다음 a 적용 (행렬과 같은 오른쪽 우선)

transform.rotation = transform.rotation * q;  // 자기 축(로컬) 기준으로 추가 회전
transform.rotation = q * transform.rotation;  // 월드 축 기준으로 추가 회전

고개 회전과 오늘 배운 변환

고개를 돌릴 때 눈의 움직임 = 회전 + 이동 — 눈은 목에서 떨어진 오프셋(고정된 간격) 위치

\[ p_{\text{눈}} = T_{\text{목 위치}} \cdot R_{\text{고개}} \cdot o_{\text{목→눈}} \]

오른쪽부터 : 오프셋 o 를 고개 회전으로 돌리고 → 목 위치로 옮김 = 순서 · 2 의 T · R (회전 먼저)

숫자 예 : 눈이 목 앞 \( o = (0,\,0,\,0.1) \) m, 오른쪽으로 90° → \( (0.1,\,0,\,0) \) — 눈이 약 14 cm 이동

- (0,0,0.1) 에서 (0.1,0,0) 까지 직선 거리 = √(0.1² + 0.1²) ≈ 0.14 m - 목 모델(neck model) : 회전만 추적하는 3DoF 기기(옛 Oculus Go, 카드보드)가 위치 대신 쓰던 보정 방법 - 6DoF = 회전 3 + 위치 3, 3DoF = 회전 3 만

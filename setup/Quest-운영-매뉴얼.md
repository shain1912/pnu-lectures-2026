# Quest 운영 매뉴얼 (C5)

**컴퓨터그래픽스 (VF3500076) · 11~15주 VR 실기 · 조성호**

- 대상 기기 : **Meta Quest 3** (Quest 3S 도 대부분 동일)
- 읽는 사람 : 학생 전원 (1~7절) · 교수·조교 (8~9절 운영표)
- 기준 문서 : Meta Horizon OS Developers «Device Setup» · Meta 고객센터 안전·청소 안내 · 수업 계획서 1-1~1-4
- **주의** : Meta 앱·헤드셋 메뉴 이름과 위치는 업데이트마다 바뀜 → 이 문서에서 «버전마다 다름» 표시가 붙은 항목은 **비슷한 이름을 찾아 진행**

## 0. 용어 풀이

| 용어 | 쉬운 뜻 |
|---|---|
| 개발자 모드 (Developer Mode) | 스토어 밖에서 만든 앱(내 빌드)을 헤드셋에 설치·실행할 수 있게 하는 스위치 |
| 개발자 조직(팀) · 인증 | 개발자 모드를 켜기 위한 전제 — Meta 개발자 대시보드에서 만든 팀 + 본인 확인 |
| adb (Android Debug Bridge) | PC 와 Android 기기(Quest)를 잇는 명령줄 도구 — 앱 설치·로그 확인 |
| USB 디버깅 | PC 가 adb 로 헤드셋을 조작해도 된다는 허락 |
| 가디언 / 경계 (Guardian / Boundary) | 착용자가 움직여도 안전한 바닥 구역 — 벗어나면 경고 격자 표시 |
| 패스스루 (Passthrough) | 헤드셋 카메라로 바깥 실제 방을 보여 주는 기능 |
| 스포터 (Spotter) | 착용자 옆에서 주변 안전을 지키는 짝 |
| SSQ | 멀미 증상 설문 (Simulator Sickness Questionnaire) — 12·14주 사용 |

## 3. 개발자 모드 켜기 (11주차 첫 시간 · 학생)

전제 : 2절 인증 완료 · 헤드셋이 **본인 Meta 계정**과 페어링 (대여 헤드셋은 조교가 사전 페어링한 공용 계정일 수 있음 → 13절 참고)

**휴대폰의 Meta Horizon 앱** 에서 (버전마다 다름)

1. Meta Horizon 앱 실행
2. 툴바의 **헤드셋 아이콘** (또는 메뉴 → **기기 / Devices**)
3. 화면 위쪽의 **페어링된 헤드셋** 선택
4. 헤드셋 그림 아래 **Headset Settings** (헤드셋 설정)

6. 헤드셋 **재시작** (전원 버튼 길게 → 다시 시작) — 재시작해야 반영되는 경우 많음

- Developer 탭의 **MTP Notification** 켬 → USB 연결 시 파일 전송 알림 표시 (Meta 문서 권장)

## 4. USB 연결 · USB 디버깅 허용

### 케이블

- **USB-C 데이터 전송** 케이블 필수 — 충전 전용 케이블은 연결돼도 기기 인식 불가
- 확인법 : 연결 후 헤드셋에 «USB 디버깅 허용» 또는 «데이터 접근 허용» 창이 뜨면 데이터 케이블
- USB 허브·연장선보다 **PC 본체 포트 직결** 권장

### Windows 만 — Oculus ADB Drivers 설치

1. Meta 개발자 사이트 → **Oculus ADB Drivers** 페이지 → Download
2. zip 압축 해제
3. `android_winusb.inf` **우클릭 → 설치**
4. 실습실 PC 는 관리자 권한 필요 → **10주차에 조교가 일괄 설치**

macOS : 드라이버 설치 불필요 · 처음 연결 시 macOS 의 «액세서리 연결 허용» 창이 뜨면 **허용** (macOS 버전마다 다름)

### 허용 절차

1. 헤드셋 착용 상태로 케이블 연결
2. 헤드셋 안 창 **«Allow USB debugging?»** → **Always allow from this computer** (이 컴퓨터에서 항상 허용) 체크 → **OK**
3. «데이터 접근 허용» 창은 파일 복사용 — 빌드 설치와 무관 (허용해도 무방)
4. PC 에서 확인

```bash
adb devices
# 2G0YC1ZF8X0123   device        ← 정상
# 2G0YC1ZF8X0123   unauthorized  ← 헤드셋 안 허용 창 미확인 → 착용하고 OK
# (빈 목록)                       ← 케이블 · 드라이버 · 개발자 모드 확인
```

> adb 위치 : Unity 설치 시 함께 설치됨 — `setup/빌드-가이드.md` 6절

## 5. 무선 adb (보조 경로)

- 수업 기본 경로 = **USB** · 무선은 케이블 부족·교체 지연 시 보조
- **학교 Wi-Fi 는 기기 간 통신 차단(클라이언트 격리)인 경우 많음** → 실습실 네트워크 정책 전산 담당 확인 필요 · 안 되면 USB 로 복귀

### 방법 A — 명령줄

```bash
# 1) USB 로 먼저 연결 (adb devices 에 device 표시 확인)
adb tcpip 5555
# 2) 헤드셋 IP 확인
adb shell ip addr show wlan0        # inet 192.168.x.x 부분
#    또는 헤드셋 설정 → Wi-Fi → 연결된 네트워크 → 상세 (버전마다 다름)
# 3) 케이블 분리 후
adb connect 192.168.x.x:5555
adb devices                          # 192.168.x.x:5555  device
```

- 헤드셋 **재시작하면 해제** → 1)부터 다시
- PC 와 헤드셋이 **같은 네트워크**여야 함

### 방법 B — Meta Quest Developer Hub (MQDH)

- Windows · macOS 지원 · 헤드셋 연결 후 Device Manager 의 **ADB over Wi-Fi** 토글 (버전마다 다름)
- MQDH 는 APK 드래그 설치 · 화면 캐스트 · 로그 확인에도 사용 → `setup/빌드-가이드.md` 8절

## 6. 가디언(경계) 설정

### 규칙 (계획서 1-3)

- 플레이 구역 **1인 2 m × 2 m** · 책상·의자·가방 치운 뒤 설정
- 실습은 기본 **Roomscale(룸스케일)** — 걸어 다니는 실습 · 앉아서 하는 체험은 **Stationary(고정)** 경계

### 절차 (버전마다 다름)

1. 헤드셋 착용 → 처음 켤 때 경계 설정 안내가 뜨면 따라 진행
2. 다시 설정 : Quick Settings → 설정 → **Boundary(경계)** 또는 **Physical Space(물리적 공간)** → Boundary
3. 패스스루 화면에서 바닥 높이 확인 → 컨트롤러로 바닥에 경계선 그리기 (Quest 3 는 방 자동 스캔 제안이 뜰 수 있음)
4. 확인 : 경계 근처로 손을 뻗었을 때 격자가 나타나는지

| 하면 안 되는 것 | 이유 |
|---|---|
| 경계 끄기 | 실습실 책상·벽 충돌 |
| 다른 사람 구역과 겹치게 설정 | 두 착용자 충돌 |
| 경계 밖으로 몸을 기울여 물체 잡기 | 경계 격자는 «경고» 일 뿐 · 실제 장애물은 그대로 |

- 시점 : **9주차 교수·조교 일괄** · 학생은 수업 중 업데이트 금지 (재시작 10~30분 소요 가능)

## 8. 위생·안전 규칙 (계획서 1-3)

### 착용 전

- [ ] 2인 1조 · **스포터 지정** (11절)
- [ ] 경계 설정 완료 · 주변 2 m 비움
- [ ] 위생 커버(일회용 또는 실리콘 커버) 1인 1매
- [ ] 안경 착용자 : 안경 스페이서 장착 · 안경이 렌즈를 긁지 않는지 확인
- [ ] 스트랩 조절 : 뒤통수 아래쪽에 걸고 위 스트랩으로 무게 분산 → 렌즈 위치(IPD) 조절해 글자가 가장 선명한 지점

### 세션 규칙

- 한 세션 **최대 10분** → 헤드셋 해제 후 휴식 (계획서 기준 · Meta 일반 안내는 30분마다 휴식)
- 어지럼·두통·메스꺼움 호소 → **즉시 중단** (9절 멀미 프로토콜)
- 케이블 연결 상태로 걷지 않기 — 빌드 설치 후 **케이블 분리하고** 체험
- 착용 중 음료 금지 · 헤드셋 착용한 채 이동 금지 (스포터가 의자로 안내)

### 렌즈·기기 보호

- **렌즈 직사광선 금지** — 창가 책상 위에 렌즈가 해를 향하게 두면 렌즈가 햇빛을 모아 디스플레이 손상 (짧은 시간도 위험) → 보관 시 렌즈 덮개 또는 렌즈가 아래를 향하게
- 렌즈 청소 : **마른 광학용 극세사 천**으로 중앙 → 바깥 원을 그리며 · 물기는 천 모서리만 살짝 · 렌즈에 액체 직접 분사 금지 · 알코올·세정제 금지

### 반납 시 청소 (Meta 청소 안내 기준)

| 부위 | 방법 | 금지 |
|---|---|---|
| 렌즈 | 마른 극세사 천 | 알코올 · 세정제 · 휴지 |
| 폼 페이스 인터페이스 | 분리 → 마른 극세사로 먼지 제거 · 손세탁은 순한 세제 + 찬물 후 완전 건조 | **알코올** · 화학 세정제 · 물에 담그기 |
| 실리콘 커버 | 닦아서 청소 가능 → **무알코올 항균 티슈**로 닦고 건조 | 젖은 채 장착 |
| 헤드셋 외관 · 컨트롤러 | 무알코올 항균 티슈 · 물기 없이 | 단자·센서 구멍에 물기 |

> 계획서의 «알코올 티슈로 페이스 인터페이스 세척» 은 Meta 안내(폼 인터페이스 알코올 금지)와 충돌 → **실리콘 커버를 씌워 운영하고, 커버만 무알코올 항균 티슈로 닦는 방식**으로 정리

## 9. 멀미 대응 프로토콜 — 3단계 (계획서 1-4 · 12·14주 필수 고지)

| 단계 | 신호 (본인 또는 스포터가 관찰) | 조치 |
|---|---|---|
| **1** | 미열감 · 침 분비 증가 · 하품 · 식은땀 | **이동 중단** · 정지 화면에서 먼 곳 응시 · 스포터에게 알림 |
| **2** | 어지러움 · 두통 · 눈 피로 · 초점이 안 맞음 | **헤드셋 해제** · 의자에 착석 · 창밖 원거리 응시 · 물 |
| **3** | 메스꺼움 · 구역 | **세션 종료 · 당일 재체험 금지** · 증상 기록 · 30분 이상 휴식 후 귀가 |

- 증상은 **헤드셋을 벗은 뒤에도 30분 이상** 남을 수 있음 (LaValle 12.3) → 3단계 경험 직후 **운전·자전거 금지** 안내
- 원인 쪽 조치 : 해당 빌드의 가속 이동·회전 확인 → 12주 컴포트 설계 자료로 사용
- **12주 멀미 유발 실습 = 본인 동의 후 참여 · 대체 과제 제공** · 거부·중도 포기에 불이익 없음
- 체험 전후 **SSQ** 기록 → 12·14주 데이터 (해석 한계는 12주 슬라이드)
- 참고 수치 : VR 연구 참가자 중도 포기 평균 약 15.6% (Souchet et al. 2023) → 중단은 드문 일이 아님을 사전 고지

```
[ ] 이상 보고 : 흠집 · 트래킹 불량 · 버튼 불량 → 조교에게 구두 + 기록
[ ] 반납 시각 ____:____ · 확인 조교 서명
```

### 분실·파손

- 즉시 조교·교수에게 보고 · 학과 기자재 규정 적용 (**학과 확인 필요** : 배상 기준)
- 렌즈 직사광선 손상은 보증 제외 가능성 → 보관 규칙 준수

## 11. 2인 1조 스포터 운영

| 역할 | 하는 일 | 하지 않는 일 |
|---|---|---|
| **착용자** | 체험 · 증상 느끼면 바로 말하기 · 경계 안에서만 이동 | 경계 밖으로 몸 기울이기 · 케이블 연결 상태로 걷기 |
| **스포터** | 주변 2 m 비우기 · 다른 조와 거리 확인 · 시간 재기(10분) · 증상 관찰 · 구두 안내 («왼쪽에 책상, 반 걸음») · 기록(1분 소감 메모) | 착용자를 갑자기 잡아끌기 (놀라서 넘어짐) · 화면 보느라 주변 감시 소홀 |

### 진행 순서 (조당 20분)

1. 스포터가 경계·주변 확인 → 착용자 착용 (1분)
2. 체험 **최대 10분** · 스포터는 시간 알림 (8분에 «2분 남음»)
3. 해제 → 1분 소감 메모 (놀란 점 · 불편한 점) · 증상 있으면 9절 단계 기록
4. **역할 교대** · 커버 교체

### 스포터의 말 (예시)

- 시작 : «경계 확인했어. 시작해도 돼»
- 접근 경고 : «멈춰. 오른쪽에 사람 있어»
- 중단 : «잠깐 멈추고 가만히 서 있자. 괜찮아?»
- 해제 안내 : «내가 헤드셋 받을게. 의자 바로 뒤에 있어»

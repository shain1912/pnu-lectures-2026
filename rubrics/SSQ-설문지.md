# SSQ 시뮬레이터 멀미 설문지 (수업용)

- 원 척도 : Simulator Sickness Questionnaire — Kennedy, Lane, Berbaum & Lilienthal (1993), *International Journal of Aviation Psychology* 3(3):203–220
- 용도 : 12주 멀미 유발본·완화본 비교 · 14주 플레이테스트 · 15주 시연 (체험 **직전·직후** 같은 양식으로 2번)
- 한국어 표기 : 수업용 번역 — 공식 표준 한국어판 없음 (Balk et al. «SSQ Twenty Years Later» 지적). 의미가 헷갈리면 **영어 원문 문항명**을 기준으로 판단

## 1. 작성 방법

- 지금 이 순간 느끼는 상태를 증상마다 하나씩 표시
- 척도 : **0 없음 (None) · 1 약간 (Slight) · 2 보통 (Moderate) · 3 심함 (Severe)**
- 체험 **직전**에도 반드시 작성 (원래 두통·피로가 있는지 = 기저선)
- 체험 **직후**에는 헤드셋을 벗고 1분 안에 작성
- 정답 없음 · 남과 비교 금지 · 좋게 보이려고 낮춰 적지 말 것 (설계 개선용 자료)

### 문항 풀이 (헷갈리기 쉬운 것)

- **5 초점 맞추기 어려움** : 글자·물체에 눈의 초점이 잘 안 맞는 느낌
- **10 머리가 꽉 찬 느낌** : 머리가 무겁고 압박되는 느낌 (두통과 구분)
- **13 눈 감은 상태의 어지러움** : 잠깐 눈을 감았을 때도 어지러운가
- **14 현기증** : 내가 또는 주변이 회전하는 듯한 느낌
- **15 속이 거북함** : 메스꺼움까지는 아니지만 배 속이 신경 쓰이는 상태

## 3. 점수 계산

### 3-1. 하위척도 문항 대응

세 묶음은 각 7문항 · **6개 문항은 두 묶음에 동시에 들어감** (표의 ● 두 개)

- **N 오심 (Nausea)** : 속·자율신경 쪽 증상
- **O 안구운동 (Oculomotor)** : 눈·두통·피로 쪽 증상
- **D 방향감각 (Disorientation)** : 어지러움·균형 쪽 증상

### 3-2. 공식

1. 묶음별 **원점수** = 그 묶음에 속한 문항 점수의 단순 합 → N<sub>r</sub> · O<sub>r</sub> · D<sub>r</sub> (각 0~21)
2. 가중치 곱하기

$$N = N_r \times 9.54 \qquad O = O_r \times 7.58 \qquad D = D_r \times 13.92$$

$$TS = (N_r + O_r + D_r) \times 3.74$$

| 점수 | 가중치 | 최댓값 |
|---|---|---|
| N | × 9.54 | 21 × 9.54 = 200.34 |
| O | × 7.58 | 21 × 7.58 = 159.18 |
| D | × 13.92 | 21 × 13.92 = 292.32 |
| TS 총점 | (세 원점수 합) × 3.74 | 63 × 3.74 = 235.62 |

- 가중치의 의미 : 원 개발 표본(비행 시뮬레이터)에서 세 묶음의 점수 범위를 비슷하게 맞추려는 환산 계수
- **흔한 실수** : TS 를 «16문항 단순 합 × 3.74» 로 계산 → 두 묶음에 걸친 문항이 한 번만 들어가 값이 달라짐 · 반드시 세 원점수의 합 사용

### 3-3. 손계산 예

체험 직후 응답 : 1번 1 · 4번 1 · 8번 1 · 11번 1 · 12번 1 · 나머지 0

| 묶음 | 포함된 응답 | 원점수 | 가중 점수 |
|---|---|---|---|
| N | 1번(1) · 8번(1) | 2 | 2 × 9.54 = 19.08 |
| O | 1번(1) · 4번(1) · 11번(1) | 3 | 3 × 7.58 = 22.74 |
| D | 8번(1) · 11번(1) · 12번(1) | 3 | 3 × 13.92 = 41.76 |
| TS | (2 + 3 + 3) | 8 | 8 × 3.74 = **29.92** |

참고 : 이 학생의 16문항 단순 합은 5 → 5 × 3.74 = 18.70 ≠ 29.92 (위 «흔한 실수» 의 예)

## 5. 해석 규칙 (반드시 지킬 것)

1. **같은 사람의 전후 비교만** — «TS 30 이상이면 위험» 같은 절대 기준은 합의되지 않음 · HMD 사용자 기준 점수(규준)도 확립되지 않음
2. 비교 값은 **변화량** — 직전 점수가 0 이 아닌 사람도 많음 (원래 피곤함)
3. **순서 효과** — 두 조건을 연달아 체험하면 앞 체험의 여운이 섞임 → 사이에 휴식 · 조의 절반은 순서를 바꿈
4. **암시 효과** — 직전 설문이 증상을 떠올리게 해 점수를 올릴 수 있음 → 모든 조건에 똑같이 직전 설문을 시행해 조건 간 공평하게
5. **요구 특성** — 실험자(조원·교수)가 원하는 답을 하려는 경향 → «정답 없음» 을 미리 안내
6. 2~3명 결과로 «효과 있음» 일반화 금지 → «이번 체험에서 관찰된 변화» 로 기술
7. 참고 수치 (메타분석 평균, Saredakis et al. 2020) : 전체 TS 약 28.00 · 게임 34.26 · 컨트롤러 이동 32.55 · 실보행 16.99 — **비교 기준이지 합격선 아님**

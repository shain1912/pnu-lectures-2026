평균의 장점과 한계

평균의 장점

모든 값을 빠짐없이 반영
전체 합을 개수로 나눈 값 → 총량과 직결
계산이 쉬움 · 이후 대부분의 통계가 평균 기반

평균의 한계

모든 값을 반영 → 극단값 하나에 크게 이동
«가운데» 대신 무게중심
평균 위치에 실제 사람이 있는지는 알 수 없음

평균 = 시소의 받침점
끝에 앉은 한 사람이 무거우면 받침점이 그쪽으로 이동 · 나머지 인원수와 무관

중앙값과 최빈값

대푯값정의극단값의 영향적합한 상황
평균
mean		 전체 합 ÷ 개수 크게 받음 좌우 대칭, 극단값 없음
중앙값
median		 크기순 정렬 시 한가운데 값 거의 없음 연봉·집값·대기시간처럼 한쪽으로 늘어진 분포
최빈값
mode		 가장 자주 나온 값 거의 없음 색깔·학과처럼 숫자가 아닌 항목

중앙값 : 순서만 반영
맨 오른쪽 연봉이 3억이든 300억이든 한가운데 사람은 그대로

극단값에 흔들리지 않는 성질 : 로버스트(robust) · 5주차 이상치 탐지에서 재등장
대푯값 · 4 ★

치우침·이상치에 따른 평균과 중앙값 변화

- 진행 순서 준수 - ① 둘 다 0 — 평균과 중앙값 일치 · "이럴 때만 평균이 대푯값 역할" 설명 - ② 치우침만 0→60→100 · 흰 선(평균)만 오른쪽 이동, 라임 선(중앙값)은 제자리 - ③ 치우침 0 복귀 후 이상치만 증가 · 점 «단 하나»가 평균을 크게 이동시키는 장면 확인 - ④ 붉은 띠를 가리키며 "이 폭만큼 평균이 현실과 어긋남" 설명 · 도입 질문의 회사 사례와 연결 - 표준편차 숫자도 함께 커지는 점 언급 → 다음 블록으로 연결

흩어짐 · 3 ★

흩어진 정도의 측정

- 수식 먼저 제시 금지 · 그림의 ①②③④ 순서대로 말로 설명 - 핵심 질문 두 개만 제시 - "왜 그냥 더하면 안 됩니까" → 합이 0 - "왜 제곱했다가 다시 제곱근을 씌웁니까" → 단위를 «점» 으로 되돌려야 해석 가능 - 계산기 사용 지양 · 학생 부담 증가
흩어짐 · 4

표준편차의 해석

평균 75점, 표준편차 10점 → «다들 75점에서 대체로 10점쯤 떨어져 있다» 평균 75점, 표준편차 2점 → «거의 다 73~77점에 몰려 있다»

단위의 중요성

표준편차 : 원래 단위 유지 — 점, 원, 분
→ 평균과 나란히 놓고 해석 가능
분산 : 단위가 점² → 해석 불가, 계산 과정에서만 활용

보고 시 한 쌍으로 제시

평균만 적은 보고서 = 미완성
평균 옆에 흩어짐 지표 필수
평균 75점 (표준편차 10점, n=32)

«평균에서 몇 표준편차 떨어져 있나»를 숫자 하나로 표현 → 5주차 z-점수

이번 주 명세

[목표]
내 데이터의 숫자 열 하나를 «기술통계로 요약» 하고,
평균 하나로 요약해도 되는 열인지 판정한다.

[제약]
- 결측치를 평균으로 채우지 말 것. 뺀 행 수를 밝힐 것
- 이상치를 임의로 지우지 말 것
- 그래프 색은 지정하지 말고 기본값으로 둘 것

[검증 조건]
- 평균과 중앙값을 «함께» 보고할 것. 둘의 차이도 같이 적을 것
- 표준편차와 함께 n(사용한 행 수) 을 반드시 적을 것
- 분포를 «반드시 그릴 것» — 히스토그램, 구간 20개 이상
- 최솟값·최댓값과 그 값을 가진 행을 같이 보여줄 것
- 마지막 줄에 한 문장으로 답할 것:
  «이 열은 평균으로 요약해도 되는가 / 안 되는가 · 그 이유»

[비목표]
- 상관, 예측, 통계적 검정
- 예쁜 그래프 꾸미기

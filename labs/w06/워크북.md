## 0. 시작 전 2분 — 용어 다시 보기

| 용어 | 쉬운 뜻 |
|---|---|
| 텍셀 (Texel) | 텍스처 그림의 칸 하나 (화면 칸 = 픽셀과 구분) |
| 밉맵 (Mipmap) | 텍스처를 절반씩 줄여 **미리 평균 내 둔** 축소판 묶음 · 메모리 +33% |
| 필터링 (Filtering) | 텍셀 사이를 읽을 때 값을 정하는 규칙 — Point(1개) · Bilinear(4개) · Trilinear(8개, 밉맵 두 레벨 섞기) |
| 이방성 필터 (Anisotropic) | 비스듬한 바닥에서 길쭉한 방향으로 여러 번 읽기 · Aniso Level |
| 나이퀴스트 한계 (Nyquist limit) | 무늬 한 주기당 표본(픽셀) **2개 이상** 필요 · 미달 → 가짜 무늬·반짝임 |
| 알파 블렌딩 (Alpha blending) | 반투명 섞기 · 순서가 결과를 바꿈 → 먼 것부터 그려야 함 |
| 알파 클리핑 (Alpha clipping) | 알파가 기준값 미만인 픽셀은 버리고 나머지는 불투명 · 깊이 버퍼 사용 → 순서 무관 |
| PPD (Pixels per degree) | 시야 1° 안의 픽셀 수 · Quest 3 약 25 · 모니터 약 45 · 시력 1.0 기준 60 |

## 실습 1 — 재현본 실행 · 증상 녹화 (8분)

### 개념
- 먼 바닥 픽셀 하나 = 텍셀 수십 개를 덮음 → 밉맵이 없으면 **한 점만** 읽음 → 카메라가 조금만 움직여도 흰↔검 뒤집힘

### 할 일
1. `W06_Trap` 씬에 빈 GameObject → `W06TrapTextureAlpha` · `W06Audit` 추가 → Play
2. Inspector 에서 `Move Camera` 끔 → 정지 화면 스크린샷 1장
3. `Move Camera` 켬 · `Jitter Arcmin` = 3 → **휴대폰으로 모니터 10초 녹화**
4. `Jitter Arcmin` = 0 으로 바꿔 10초 녹화 (비교용)
5. Scene 뷰에서 덤불 주위를 돌며 잎 순서가 뒤바뀌는 순간 캡처
6. Console 의 `[Audit]` 로그 복사

### 체크리스트

## 실습 2 — 필터 4종 비교 (10분)

### 개념
- Point → Bilinear 는 **확대** 문제(계단)만 해결 · **축소** 문제(반짝임)는 밉맵이 있어야 해결
- Trilinear 는 밉맵 두 레벨을 섞어 경계 띠 제거 · Aniso 는 비스듬한 바닥의 과한 흐림 보정

### 할 일
1. `W06_Fixed` 씬에 `W06FixedTextureAlpha` · `W06Audit` 추가 → Play
2. `Move Camera` 끔 (같은 지점 비교를 위해)
3. `Floor Preset` 을 4가지로 바꾸며 **같은 화면** 스크린샷 4장
4. `Move Camera` 켜고 각 프리셋에서 반짝임 유무만 관찰

### 손계산 (리포트에 사용)
- 1024 텍스처를 입힌 바닥 한 칸이 화면에서 가로 몇 픽셀인지 스크린샷에서 측정 : ___ 픽셀
- 픽셀당 텍셀 = 1024 ÷ ___ = ___
- LOD = log₂(___) ≈ ___ → 사용 레벨의 해상도 = ___ × ___

### 기록

| PointNoMip | | | | |

| TrilinearMip | | | | |

### 체크리스트
- [ ] «Bilinear 로 바꿔도 반짝임이 남는 이유» 를 텍셀 수로 설명함

## 실습 3 — 명세 → AI → 거리 페이드 Shader Graph (20분)

### 개념
- 밉맵이 «자동으로» 하는 일(멀면 평균색) 을 셰이더로 **의도적으로 디자인**
- 노드 = 수식 한 줄 : `Position(World)` → `Distance` (+ `Camera` Position) → `Smoothstep` → `Lerp` → `Base Color`

### 3-1. 명세 작성 (5분) — 4칸을 모두 채울 것

```
[목표]
URP Shader Graph 로 바둑판 바닥 재질을 만든다. 카메라에서 ___ m 부터 ___ m 사이에서
무늬가 평균 회색(___)으로 부드럽게 사라진다. 노드 목록과 연결 순서로 답할 것.

[제약]
- 텍스처 : ____×____, Generate Mipmap ___, Filter Mode = ______, Aniso Level = ___
- 바닥 Tiling = ___, Wrap Mode = ______
- 그래프 : ___ Shader Graph, Surface Type = ______, Sample Texture 2D LOD 사용 금지

[검증 조건]
- 같은 카메라 경로 10초 녹화 : ________ 비교
- 진단 로그 : mipmapCount ___ , renderQueue ≥ 3000 인 재질 ___ 개
- 손계산 : 거리 ___ m 에서 smoothstep 값 = ___ → 화면 결과와 일치하는가

[비목표]
- __________________
```

> 명세 각 줄이 **예/아니오로 판정 가능한가** 스스로 확인 · «예쁘게» · «자연스럽게» 금지

### 3-2. AI 에게 요청 (5분)
- 명세를 그대로 붙여 넣기
- AI 가 `.shadergraph` 파일 자체를 쓰려 하면 → «노드 이름 · 설정값 · 연결(어느 출력 → 어느 입력) 목록으로 다시» 재요청
- 받은 답에서 확인 : `Sample Texture 2D LOD` 를 쓰지 않았는가 · Surface Type 이 Opaque 인가

### 3-3. 직접 구성 (7분)
1. Project 창 → Create → Shader Graph → URP → **Lit Shader Graph** → 이름 `SG_DistanceFadeFloor`
2. AI 가 준 목록대로 노드 배치 · 연결 → Save Asset
3. 그래프로 머티리얼 생성 → 바닥에 적용 · 텍스처 슬롯에 바둑판 텍스처

### 3-4. 검증 (3분)
- 카메라를 Edge1 거리 · 중간 · Edge2 거리에 두고 스크린샷 3장
- 손계산 : 거리 d 에서 t = (d − E₁) ÷ (E₂ − E₁) · smoothstep = t² × (3 − 2t)
  - 예 : E₁ = 5, E₂ = 20, d = 12 → t ≈ 0.467 → 약 0.45 → 무늬 55% + 회색 45%

| 항목 | 기록 |
|---|---|
| AI 첫 답의 문제점 (있다면) | |
| 재프롬프트 내용 | |
| 거리 ___ m 손계산 값 / 화면 판단 | ___ / ___ |

### 체크리스트
- [ ] 명세 4칸이 모두 채워졌고 숫자·설정 이름이 들어 있음
- [ ] AI 답을 그대로 쓰지 않고 금지 조항 위반 여부를 확인함
- [ ] 손계산 1개를 화면과 대조함
- [ ] 재프롬프트가 있었다면 **무엇이 틀려서** 다시 요청했는지 기록함

## 실습 4 — 잎 재질 Blend → Clip (10분)

### 개념
- 알파 블렌딩 결과 = 순서에 따라 달라짐 (빨강→파랑 vs 파랑→빨강 손계산)
- Unity 의 반투명 정렬 = **물체 중심 거리** 기준 · 교차한 카드는 어떤 순서도 정답 아님
- 잎처럼 «구멍만 뚫리면 되는» 모양 → Opaque + Alpha Clipping → 깊이 버퍼가 순서 해결

### 할 일
1. `W06_Fixed` 씬 · `Leaf Mode` = AlphaBlend → 덤불 주위를 돌며 뒤바뀜 확인
2. 덤불을 화면 가득 채운 지점에서 `W06Audit` 프레임타임 기록
3. `Leaf Mode` = AlphaClip → 같은 지점에서 재측정
4. `Alpha Clip Threshold` 0.2 · 0.5 · 0.8 비교 → 잎 두께 변화 관찰
5. (선택) Frame Debugger 로 두 모드의 그리기 단계 비교

### 기록

| Leaf Mode | 순서 뒤바뀜 | renderQueue | 프레임타임 (ms) |
|---|---|---|---|
| AlphaBlend | | | |
| AlphaClip | | | |

### 체크리스트
- [ ] 뒤바뀜이 생기는 이유를 «물체 중심 거리 정렬» 로 설명함
- [ ] renderQueue 3000 → 2450 변화를 로그로 확인함
- [ ] Alpha Clipping 의 단점(가장자리 계단)과 완화 방법(MSAA 4x)을 적음
- [ ] 씬에서 **정말 반투명이 필요한 재질**(유리·물 등)이 무엇인지 목록화함

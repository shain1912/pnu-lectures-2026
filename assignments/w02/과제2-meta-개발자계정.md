**컴퓨터그래픽스 (VF3500076) · 디자인앤테크놀로지전공 · 조성호**

- **제출 기한** : 3주차 수업 시작 전 (목 14:00)
- **제출처** : PLATO 과제란 (스크린샷 2장)
- **배점** : Pass / Fail — 미이수 시 **11주차 VR 실습 참여 불가**

## 지금 하는 이유

- 11주차 : Quest 3 를 1인 1대로 배부 → 본인이 만든 씬에 직접 진입
- **Quest 의 기본 상태** : Meta 스토어에서 받은 앱만 실행 가능
- 본인 빌드 실행 조건 : 헤드셋 **개발자 모드** → 개발자 모드 조건 : **인증된 개발자 계정**
- 인증 과정에 **본인 확인 절차** 포함 → 즉시 완료되지 않을 가능성

> **미루면 11주차 실습 불가.** 오늘 저녁에 완료 권장 · 소요 시간 약 20분

## 절차

### 1단계 · Meta 계정 준비

- 기존 계정 보유 시 건너뜀
- 신규 생성 : <https://www.meta.com/>

> 학교 이메일 아니어도 무방 · **본인이 계속 사용할 계정**으로 선택
> 학기 내내 사용하며 졸업 후 포트폴리오에도 활용

---

### 2단계 · 개발자 팀(조직) 만들기

개발자 모드의 전제 조건 : **개발자 팀 소속** — 1인 팀도 생성 필요

1. **Meta Horizon Developer Dashboard** 접속
   → <https://developers.meta.com/horizon/manage/>
2. Meta 계정으로 로그인
3. **Create New Team**(새 팀 만들기) 선택
4. 팀 정보 입력 후 생성

**팀 이름 정하는 기준**

- 본인 이름 또는 활동명 (예 : `Hong Gildong Studio`)
- 스토어 출시 시 **개발사 이름으로 노출**되는 항목
- 임의로 정할 경우 이후 변경 부담

---

### 3단계 · 계정 인증 (핵심 단계)

**이 단계 통과 후에만 개발자 모드 사용 가능**

1. Developer Dashboard 의 **Verification(인증)** 탭으로 이동
2. 요청 시 Meta 계정으로 로그인
3. 아래 **둘 중 하나**를 선택해 인증

| 방법 | 내용 | 비고 |
|---|---|---|
| **A. 휴대폰 SMS 2단계 인증** | 휴대폰 번호 등록 후 SMS 인증 | 국내 통신 3사 정상 동작 · **권장** |
| **B. 결제수단 등록** | 카드 등록 (**PayPal 불가**) | 요금 청구 없음 · SMS 실패 시 |

> SMS 미수신 시 국가번호(+82) 적용 여부와 번호 앞자리 0 제거 여부 확인
> 그래도 실패하면 B 로 전환

---

### 4단계 · 개발자 모드 켜기 (Quest 배부 후)

> **현재는 헤드셋 미배부 상태 → 11주차에 함께 진행**
> 절차는 미리 읽어 둘 것 · 제출물에 미포함

전제 조건

- 인증된 Meta 개발자 계정 (3단계 완료)
- 만 18세 이상
- 헤드셋에 기기 수준 제한 없음

절차 — **휴대폰의 Meta Horizon 앱**에서

1. Meta Horizon 앱 실행
2. 툴바의 **헤드셋 아이콘** 탭
3. 화면 상단의 **페어링된 헤드셋** 항목 탭
4. 헤드셋 이미지 아래 **Headset Settings**(헤드셋 설정) 탭
5. **Developer Mode**(개발자 모드) 탭
6. 토글 **켬**

Windows 개발 환경 : **Oculus ADB Drivers** 설치 필요 (11주차 안내)
